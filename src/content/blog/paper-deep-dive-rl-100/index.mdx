## 1. 论文概述

**【Paper】** RL-100 关注的不是“机器人能否完成一次任务”，而是能否在真实环境中同时满足可靠性（success rate）、效率（time-to-completion）和鲁棒性（长时间运行、扰动恢复）。作者在 Dynamic Push-T、Agile Bowling、Pouring、Soft-towel Folding、Dynamic Unscrewing、Orange Juicing 两个子任务以及 Box Folding 共八项任务上评估。

### 一句话总结

**【Paper】** 先用示范训练扩散 visuomotor policy，再反复执行“离线改进 → 真实 rollout 扩充 → 重新 BC”，最后进入在线 RL。离线与在线 RL 共享逐去噪步的 clipped PPO 形式，IL 仍使用监督噪声预测；一步 consistency student 在 RL 期间同步学习。本文按 [arXiv v4 全文及补充材料](https://arxiv.org/pdf/2510.14830v4) 核查。

### 核心贡献

**【Paper】**

1. 提出三阶段 IL → iterative offline RL → online RL 的真实机器人后训练流程，在每轮固定数据集上优化，再通过真实交互扩大该数据集；“离线”不等于整个训练不接触机器人。
2. 将扩散采样写成嵌套的 two-level MDP，在所有去噪步共享环境级 advantage，统一离线和在线的 clipped PPO 目标。
3. 用 reconstruction / VIB 正则稳定视觉表征，并用 consistency distillation 将 $K$ 步采样压缩到一步。
4. 论文实验覆盖 2D/3D 表征与单步/动作块控制；**【Code】** 当前官方实现另提供 flow policy 与 flow 蒸馏入口，不能将代码的全部组合都视为本文真实任务已验证的配置。
5. 八项真实任务的 DDIM 与 CM 评测合计 1000/1000 成功；零样本、少样本、扰动测试的场景平均分别为 90.0%、86.7%、96.0%。这是任务专用策略的有限评测，不是一个通用策略在开放环境的可靠性保证。

## 2. 背景与相关工作

**【Paper】** 纯行为克隆（BC）拥有良好的人类先验，却继承了 teleoperator 的慢动作、覆盖不足和偶发错误，形成 imitation ceiling。直接在真实硬件上做 online RL 又会遭遇样本昂贵、分布偏移和性能崩溃。扩散策略能表示连续、多模态动作，但多步去噪使 RL 的 credit assignment 更困难。

**【Analysis】** RL-100 的关键视角是把“示范数据的安全性”和“交互数据的改进能力”放在同一优化接口中：示范负责把策略锚定在可执行动作流形，RL 只需在其附近寻找更快、更稳的轨迹。

## 3. 问题定义

**【Paper】** 每个时间步输入视觉观测 $o_t$（RGB 或点云）与机器人本体状态 $q_t$（关节位置/速度、夹爪状态），输出单步动作 $u_t\in\mathbb{R}^{d_a}$ 或长度为 $n_a$ 的动作块 $[u_t,\ldots,u_{t+n_a-1}]$。策略通过条件扩散生成动作，并按维度归一化。具体动作空间随任务变化：Push-T/Bowling 使用平面增量，双臂任务使用末端位姿/夹爪命令，灵巧手任务还包含手指关节；不能统一写成二维位姿增量。

任务奖励大多是成功时终止并给 $+1$、其余时刻为 0 的稀疏奖励，另加时间步惩罚和动作抖动惩罚；Dynamic Push-T 使用基于位姿误差、推进进度和动作平滑度的 dense reward。**【Paper】** 实验覆盖 UR5、Franka + LeapHand、xArm–Franka 等单臂和双臂 embodiment。

## 4. 方法

### 4.1 Overall Architecture

![RL-100 三阶段训练与策略分解（论文 Figure 6）](https://pic.hana0721.top/blog/paper-deep-dive-rl-100/fig6.5trrjbo02z.webp)

**【Paper】** 观测编码器将点云/RGB 与 proprioception 融合为条件 $c_t$，扩散 actor 经过 $K$ 次去噪生成动作；离线阶段用改进策略产生新 rollout 并重新加入数据集，在线阶段直接在真实硬件上针对残余失败微调，部署时可切换 DDIM 或一步 consistency model。

### 4.2 核心模块

#### 观测编码器与稳定正则

- **输入**：最近 $n_o$ 帧观测和机器人状态。
- **输出**：视觉特征 $z_t$，与 proprioceptive feature 拼接形成 $c_t$。
- **【Code】** `rl_100/policy/rl100_3d.py` 提供 `DP3Encoder`、`DP3EncoderReconVIB` 和 `PointNetImaginationExtractorGP`；`rl100_3d_epsilon.yaml` 默认选 DP3 编码器与 64 维输出，也有 2D 分支。论文补充材料的点云处理写 512 点，而效率比较处写 DP3 使用 1024 点；应按具体配置理解，不能将 512 当作所有实验的统一输入。
- **【Paper】** reconstruction loss 用 Chamfer distance 重建点云并重建状态，VIB 用 KL 项约束潜变量；方法总述将两项 RL 正则权重设为 IL 的十分之一；但离线 RL 小节又明确共享并冻结 IL 预训练编码器，只更新各模块的任务头。联合编码器更新的收益由在线实现和仿真 Door 消融支持，不能笼统写成全部离线/在线阶段始终端到端更新。

#### Diffusion / Flow Actor

- **输入**：带噪动作 $a^k_t$、denoising timestep $k$ 和条件 $c_t$。
- **输出**：噪声或 clean-action 预测，最终得到单动作或动作块。
- **【Code】** `RL1003D` 可实例化 `ConditionalUnet1D`、轻量 `SampleConditionalUnet1D`、MLP/SkipNet，以及 DDIM、consistency 和 flow scheduler；`n_action_steps` 控制动作块长度。
- **【Analysis】** 单步模式适合 bowling 等需要快速反应的任务；chunking 通过一次输出连续动作减少抖动，更适合 folding、assembly 等长时协调任务。

#### Iterative Offline RL 与 OPE Gate

**【Paper】** 每轮先用 IQL 训练 $Q,V$ 和 transition model，再以 PPO surrogate 更新候选策略。Approximate model-Q（AM-Q）离线评估候选策略与当前 behavior policy，只有当估计回报提升超过阈值 $\delta$ 时才接受更新；随后 rollout、合并数据并重新 BC。论文式 (9) 取 $\delta=0.05|\hat J_{\mathrm{AM-Q}}(\pi_b)|$。AM-Q 是在学习到的转移模型中累计 $Q$ 值的筛选分数，并非候选策略在真实环境测得的回报。gate 降低坏更新风险，但模型与 critic 同时失准时仍会误判；估计分数单调不构成真实回报或硬件安全的保证。

#### One-step Consistency Distillation

**【Paper】** consistency actor 以多步 diffusion actor 为 teacher，在离线和在线 RL 同时训练。teacher 使用 stop-gradient，RL 继续优化 teacher，而 consistency loss 让 student 从初始噪声直接输出动作。其回归目标是同一带噪输入经 teacher 沿既定 schedule 去噪至干净动作后的 stop-gradient 输出（补充式 S23），并非重新采一条不相关的 teacher 动作。DDIM 的 10 次网络调用压成一次，不意味着整机快十倍：Box Folding 的 RL-100 DDIM 为 45.6 s、CM 为 41.4 s，约快 1.10 倍；与 DP-2D 的 65.1 s 比较还混合了表征、策略和轨迹长度的变化。

### 4.3 关键公式

行为克隆的噪声预测目标为

$$\mathcal{L}_{IL}=\mathbb{E}\left[\|\epsilon-\epsilon_\theta(a^k_t,k,c_t)\|_2^2\right].$$

其中 $\epsilon$ 是高斯噪声，$k$ 是扩散步，$\epsilon_\theta$ 是 denoiser。它让策略先复制示范中的动作分布。

对一个环境动作内部的 $K$ 个去噪转移，统一 PPO 目标为

$$J(\pi)=\mathbb{E}\left[\sum_{k=1}^{K}\min\left(r_k A_t,\operatorname{clip}(r_k,1-\varepsilon,1+\varepsilon)A_t\right)\right].$$

其中 $r_k=\pi(a^{k-1}|a^k,c_t)/\pi_b(a^{k-1}|a^k,c_t)$ 比较同一去噪转移在新旧策略下的密度；$A_t$ 为环境步 advantage，$\varepsilon$ 为 PPO clip 范围。训练必须使用方差严格为正的 stochastic DDIM 高斯转移，才能计算该密度。部署的确定性 DDIM 是退化映射，不能直接拿它计算高斯 log-likelihood（补充式 S16–S22）。

离线使用 $A_t^{\mathrm{off}}=Q(s_t,a_t)-V(s_t)$；在线使用 GAE，并固定当前 PPO batch 的旧策略。**【Analysis】** 共享 advantage 给整条去噪链相同的任务反馈，但并没有额外观测到每一步独立的因果贡献，也没有把稀疏环境奖励变成真实的稠密奖励。

**【Paper】** 若一次执行 $n_a$ 个动作，应使用块内折扣奖励 $R_{\mathrm{chunk}}=\sum_{j=0}^{n_a-1}\gamma^jR_{t+j}$，块间折扣为 $\gamma^{n_a}$。改变 chunk 长度却保持单步折扣，会改变优化问题。

在线阶段的总损失为

$$\mathcal{L}_{on}=-J(\pi)+\lambda_V\mathbb{E}(V(s_t)-\hat V_t)^2,$$

其中 $\hat V_t$ 由 GAE/bootstrapped return 得到。蒸馏阶段再加 $\lambda_{CM}\mathcal{L}_{CM}$。

## 5. 实验

### 5.1 Experimental Setup

**【Paper】** 真实任务包含动态刚体、颗粒倾倒、可变形毛巾、灵巧手旋拧、双臂折叠和榨汁子任务。Table 1 中多数单元格为 50 次；DDIM 的 Juicing–Placing 为 100 次，CM 的毛巾折叠为 250 次，CM 未评估 Juicing–Removal。因此 1000/1000 是 DDIM 的 450 次加 CM 的 550 次，既不是每个任务各 1000 次，也不是一次连续运行 1000 次。DP-2D 与 DP3 是 imitation baselines，RL-100 分别报告 DDIM 和 consistency model。

![RL-100 在零样本、少样本和人工扰动下的测试设置（论文 Figure 3）](https://pic.hana0721.top/blog/paper-deep-dive-rl-100/fig3.4qs28fs61r.webp)

### 5.2 Main Results

| DP-2D                |      45.3% | 动态、接触丰富任务明显失败                    |
| DP3                  |      67.8% | 点云表征提升 bowling，但 Box Folding 仍为 48% |

### 5.3 Ablation Study

**【Paper】** Table 1 的阶段对比支持逐步后训练的总体收益，但不是每项指标严格单调：例如 Unscrewing 的 DP-2D 为 82%，DP3 为 70%。阶段之间还改变了数据量，不能仅据此声称“移除数据飞轮”已被独立控制变量验证。

### 5.4 Generalization

**【Paper】** Table 2 的零样本六种设置平均 90.0%；少样本三种设置微调 1–3 小时后平均 86.7%，其中新容器倾倒仅 60%；扰动五种设置平均 96.0%。这些是场景等权平均，表中未给各行的 trial 分母，不应直接套用 Table 1 的 50 次。**【Analysis】** 这些测试并非只考察视觉识别，而是在检验闭环控制是否能在接触动力学变化后及时恢复。

## 6. 方法分析

### 6.1 为什么有效？

**【Analysis】** 三个环节分别解决三个瓶颈：IL 限制探索风险，迭代离线 RL 以可反复利用的真实 rollout 获得 value-directed 改进，online RL 在当前策略分布下继续探索和修正；其实际交互量并不总能忽略。共享去噪 advantage 则把稀疏任务信号分配给生成动作的每一步。

### 6.2 核心创新

1. **目标统一**：离线与在线共享 clipped surrogate，但 advantage、数据来源和参考策略不同；形式统一有助衔接，不等于严格保证转换时无性能跌落。
2. **数据飞轮**：更好的策略产生更好的数据，再用 IL 将多模态行为压回一个可部署 policy。
3. **部署共设计**：训练时就加入 consistency distillation，而不是部署前再做可能损伤性能的压缩。

### 6.3 与已有方法的本质区别

**【Analysis】** 与只做 BC 的 Diffusion Policy 相比，RL-100 明确优化成功率、完成时间和抗扰动；与从零开始 real-world RL 相比，它用示范策略提供安全先验；与仅在最终动作上加 RL 的做法相比，它把扩散链视为内部 MDP，在 denoising transition 粒度计算 ratio 和 credit。

### 6.4 关键假设

**【Paper】** 需要人工或任务逻辑提供成功终止与 reset；离线阶段依赖 IQL/transition model 的保守估计；consistency policy 假设 teacher 的多步动作分布可以被一步网络近似。**【Analysis】** 在遮挡严重、奖励判定困难或 reset 代价极高的家庭场景，这些假设仍可能成为主要瓶颈。

## 7. 局限性

### 7.1 作者明确提出的局限

**【Paper】** 作者指出未来需处理更多 clutter、遮挡、透明/高反光物体、变化光照和非平稳布局；reset 与 recovery 仍需人工参与，计划探索 learned reset policy、scripted recovery 和 failure-aware action chunking。论文也将多任务、多机器人大模型上的 scaling law 留作后续工作。

### 7.2 自己分析得到的局限

**【Analysis】** 100% 成功率来自精心设计的八项任务和有限评测次数，不能直接等价于开放世界可靠性；奖励主要是终止成功信号，效率 shaping 与 jitter penalty 的权重需要按任务调节。CM 在 Orange Juicing–Removal 上因 IK-induced pose discontinuity 和噪声敏感性未评测，说明一步蒸馏并非对所有控制模式都同样适用。毛巾任务保证两个目标角可见，纸盒使用预设折线，均有任务约束。商场七小时榨汁展示由已训练的放置/移除子策略与固定的压杆示教回放组成，不能描述为整段服务流程都由同一 RL 策略自主学会；训练与 reset 仍包含人工参与。

## 8. 启发与研究思考

**【Analysis】** RL-100 给 VLA 后训练的启发不是“把 PPO 接到任意 policy 后面”，而是先找出 policy 内部真正产生动作的随机过程，再在该过程上定义可计算的 likelihood 和 conservative update。对未来的大型 VLA，可以保留语言模型的语义先验，只把 diffusion/flow action head、offline OPE gate 和 consistency distillation 作为部署层。

**【Paper / Analysis】** 数据预算应逐行读取 Table S3。八任务相加为 **1004 条示范/15.5 h、4573 条离线扩充 rollout/54.6 h、3223 条在线 rollout/42.5 h**，合计 112.6 h 数据采集，均值约 126/572/403 条。正文仍写 804/3965/3037 条及“总计不足 100 h”，恰好漏掉 Box Folding 一行，因此不能沿用正文的八任务平均 115/566/434。这里统计的是采集时长，不是含优化、标注、复位在内的完整人力成本。

这种数据配方说明少量示范可以启动真实交互改进；它没有证明人工 reset 或奖励提供已完全自动化，也不能把 rollout 的成本视为零。
