### 一句话总结

**【Paper】** SLIM（Self-supervised Latent Interaction Model）用 0.47B 可训练参数的两流
Mixture-of-Transformers（MoT）替代大 VLM 或像素级 world model：先在轨迹中用互补的
inverse dynamics（IDM）与 forward dynamics（FDM）学习 action-grounded predictive latents，
再以 flow matching 根据当前观测、语言和本体状态生成动作 chunk；部署时不生成未来图像。

**【Paper】** 参数口径见 Appendix A.3：0.47214B = 86.58M DINOv2 + 385.56M 动作模型，**不含冻结的 T5-small**，也不含只用于 Stage 1 的 86.58M EMA encoder。论文的 P.T. 标记排除通用视觉/语言初始化；而 Stage 1 本身仍是机器人轨迹上的预训练，且包含 LIBERO-90。读者不能把“无额外具身基座预训练”理解成没有任何机器人预训练或总系统只有 0.47B 参数。

### 核心贡献

**【Paper】**

1. 将控制主体放在 observation latent 与连续 action token 的交互上，而不是每步运行大型 VLM，得到 0.47B 的紧凑策略。
2. 提出 masked trajectory prediction：IDM 从当前/未来 latent 还原动作，FDM 从当前 latent 与动作预测未来 latent，使表征同时满足两个方向的动力学约束。
3. 在原始 LIBERO 训练、不接触 LIBERO-Plus 数据的前提下，报告 97.5% 的 LIBERO 成功率与 77.45% 的零样本 LIBERO-Plus 成功率；CALVIN ABC→D 的平均成功序列长度为 4.556。
4. 真实五任务、多任务混合训练中，SLIM 的平均 progress score 为 67.8，并在论文控制的 H100 测试里以 60.6 ms/chunk、4.26 GiB 增量显存运行。

## 2. 背景与相关工作

**【Paper】** 大型 Vision-Language-Action（VLA）策略把视觉、语言与动作放入同一多模态骨干，能利用广泛语义先验，但动作引起的状态变化通常只由动作监督隐式学得。另一端，world action model（WAM）直接预测未来图像或视频—动作轨迹，动力学建模更显式，却要拟合纹理、光照等控制无关细节；若推理阶段还 rollout future，会增加闭环延迟。

**【Paper】** SLIM 的切入点是 latent-space prediction：未来不是额外要生成的视觉输出，而是训练时塑造控制表征的目标。它与 JEPA 一样预测 embedding 而非像素，但额外要求 latent 对机器人动作“可解释、可预测”。

**【Analysis】** 这并非简单缩小 VLA。关键取舍是把语言从 joint attention 序列中拆出，作为两个 stream 的 cross-attention 条件；主计算预算留给“当前状态—候选动作”的交互，因此更贴近 manipulation 的局部闭环需求。

## 3. 问题定义

**【Paper】** 在时刻 $t$，策略接收语言指令 $y$、多视角 RGB 观测 $o_t$ 与 proprioceptive state $q_t$。T5-small 将语言编码为 $\ell=g_{\mathrm{lang}}(y)$，DINOv2 视觉编码器将观测编码为 $N_z$ 个 latent：

$$
Z_t=g_\psi(o_t)\in\mathbb{R}^{N_z\times d_z}.
$$

策略输出长度为 $H$ 的连续动作 chunk：

$$
A_t=(a_t,\ldots,a_{t+H-1}).
$$

**【Paper】** 动作不做离散 tokenization；MoT 直接处理连续动作向量嵌入。训练第一阶段还可访问 $o_{t+H}$，得到 online latent $Z_{t+H}$ 与 EMA target $\bar Z_{t+H}$；第二阶段和部署阶段均不输入未来观测。

| 要素                  | SLIM 的具体选择                              |
| --------------------- | -------------------------------------------- |
| Vision encoder        | DINOv2-B/14                                  |
| Language encoder      | T5-small                                     |
| 控制状态              | 多视角视觉 patch latents + 7D proprioception |
| Action representation | 连续 7D action、chunk prediction             |
| Policy                | 16 层、hidden dim 768 的 two-stream MoT      |
| 训练目标              | Stage 1：IDM + FDM；Stage 2：flow matching   |

**【Code】** 默认 LIBERO 配置使用两路图像、224px 输入、`dense_patch` 视觉条件、$H=8$、4 个推理采样步；语言最大长度为 32 token，代码位于 `configs/libero/stage1_idm0125_fdm1_h8.yaml` 与 `stage2_policy_h8_40ep.yaml`。

## 4. 方法

### 4.1 Overall Architecture

![SLIM 的 MoT 双流骨干：observation/action joint attention，分别对语言做 cross-attention（论文 Figure 3）](https://pic.hana0721.top/blog/paper-deep-dive-slim/architecture.9ddp9bfzqo.webp)

**【Paper】** 视觉 latent 与一个状态 token 组成 observation stream；带 flow timestep 的连续动作嵌入组成 action stream；两流在每层共享 joint attention，再各自对语言做 cross-attention 和 FFN。future-slot embeddings $M_z$ 占据未来 latent 的位置，供 FDM 与策略阶段使用。

**【Paper】** 数据流只需概括为：当前 observation latent、状态、语言和 action variable 进入 MoT，MoT 输出动作速度场或未来 latent；训练/部署的完整流程分别见 4.4、4.5。

### 4.2 核心模块

#### 两流 MoT：用有方向的 attention 支持训练与缓存

**【Paper】** observation 与 action token 分别具有独立的 $Q,K,V$ 投影、AdaLN 和 FFN，但在同一个 attention 中交互。语言不混入该 attention，而是每个 stream 单独 cross-attend 到语言 token。动作 flow sampling 时，观测/语言保持固定，反复更新的是 action stream。

**【Paper / Code】** joint attention 并非所有 token 无条件双向互看。IDM 与 policy 分支阻止 observation rows 读取 action columns，动作则可以读当前、未来位置与其他动作；FDM 只阻止当前视觉/状态 rows 直接读取 action，允许 future-slot rows 读取干净动作，从而形成动作条件预测。两张图里的 mask 对应的是不同目标，不能只概括成共享 attention。

**【Code / Analysis】** 在 policy 分支，未来 slots 经过观测流后会依赖当前图像、状态和语言，但不随当前候选动作变化；因此 `build_ctx_cache()` 能一次构建逐层 context K/V，四次 `forward_action_only()` 复用它们。初始 slots 是学习常量，经过网络后并非恒定输出；它们提供的是隐式预测结构，而不是部署时逐候选动作计算未来后果、排序并选动作的规划器。

#### IDM：由状态变化反推动作

**【Paper】** 将干净动作 $A_t$ 与高斯噪声 $\epsilon$ 插值为带噪动作 $\tilde A_t^\tau$。MoT 观察 $Z_t,Z_{t+H},q_t,\ell$ 与带噪动作，预测其 velocity。因为未来 latent 是可见条件，模型要回答“什么动作造成了这次变化”。

#### FDM：由当前状态和动作预测未来 latent

**【Paper】** FDM 用 learnable mask slots $M_z$ 替换未来位置，只给出 $Z_t,A_t,q_t,\ell$，预测 $\hat Z_{t+H}$；目标来自 stop-gradient 的 EMA encoder。它迫使未来表示保留可被当前状态与动作预测的成分，而不是重建所有像素细节。

![IDM、FDM 与目标专用 attention mask（论文 Figure 2）](https://pic.hana0721.top/blog/paper-deep-dive-slim/idm-fdm.39lx6vdbfy.webp)

**【Analysis】** 两个目标提供互补约束：IDM 让观测差异对动作重建有用，FDM 让干净动作对未来表征预测有用。不过这是来自示范分布的统计约束；多个动作可能导致近似同一视觉终态，环境也可能含外因，所以不能由这些 loss 推出严格的因果可辨识性。论文未做动作干预下的因果识别检验。

### 4.3 关键公式

#### Flow matching 的插值与目标速度

**【Paper】** 对 $\epsilon\sim\mathcal N(0,I)$ 和 $\tau\sim U(0,1)$：

$$
\tilde A_t^\tau=(1-\tau)\epsilon+\tau A_t,\qquad V_t^*=A_t-\epsilon.
$$

$\tilde A_t^\tau$ 是时刻 $\tau$ 的带噪 action chunk，$V_t^*$ 是从噪声端流向数据端的目标速度。$v_\theta$ 不是直接回归动作，而是回归该速度，推理时积分得到动作。

#### Stage 1 的双向动力学损失

$$
\mathcal L_{\mathrm{IDM}}=
\mathbb E\left[\left\|v_\theta(\tilde A_t^\tau,\tau\mid Z_t,Z_{t+H},q_t,\ell)-V_t^*\right\|_2^2\right],
$$

$$
\hat Z_{t+H}=p_\theta(M_z\mid Z_t,A_t,q_t,\ell),\qquad
\mathcal L_{\mathrm{FDM}}=
\left\|\operatorname{LN}(\hat Z_{t+H})-
\operatorname{LN}(\operatorname{sg}(\bar Z_{t+H}))\right\|_1,
$$

$$
\mathcal L_{\mathrm{stage1}}=\lambda_{\mathrm{IDM}}\mathcal L_{\mathrm{IDM}}
+\lambda_{\mathrm{FDM}}\mathcal L_{\mathrm{FDM}}.
$$

**【Paper / Code】** $\operatorname{sg}$ 阻断 target 梯度；当前实现对每个 patch 的 feature 维分别做 LayerNorm，再平均 L1 差异。这会忽略各 patch 向量的整体平移和尺度，强调归一化特征结构；它既不是像素误差，也不是全局语义 token 的单点匹配。IDM 的未来条件走 online encoder，保留梯度；FDM 的未来 target 才走 EMA、stop-gradient。论文最佳联合权重为 IDM:FDM = 0.125:1。

**【Code】** 一个复现差异是训练时间采样：论文 Eq. (4) 写 $\tau\sim U(0,1)$，当前 `sample_time()` 默认先采样 $b\sim\operatorname{Beta}(1.5,1)$、截到 0.999，再令 $\tau=(0.999-b)/0.999$，并将时间离散到 1,000 个 embedding buckets。它更偏向近噪声端，不是均匀采样。Stage 2 的 `repeated_diffusion_steps=4` 是同一条件下独立重采样四组噪声/时间来估计训练 loss，不是训练时做四步 Euler 积分；部署的四步采样是另一项参数。

#### 部署一致的策略目标

$$
\mathcal L_{\mathrm{stage2}}=\mathcal L_{\mathrm{FM}}=
\mathbb E\left[\left\|v_\theta(\tilde A_t^\tau,\tau\mid Z_t,M_z,q_t,\ell)-V_t^*\right\|_2^2\right].
$$

**【Paper】** Stage 2 中真实 $Z_{t+H}$ 不再出现；它被 Stage 1 学得的 predictive slots $M_z$ 取代。因此“预测未来”只作为训练归纳偏置，不成为推理时的额外生成任务。

### 4.4 Training

**【Paper】** 阶段一从机器人轨迹自监督学习：IDM 可见当前和未来观测、FDM 可见当前观测和干净动作；阶段二由阶段一权重初始化，仅使用当前观测、状态、语言和示教动作训练可部署的 flow policy。

### 4.5 Inference

**【Paper】** 部署只需当前多视角观测、proprioception 和语言。future slots 是学习到的常量 token，不需要相机看到未来，也不生成未来帧。

## 5. 实验

### 5.1 Experimental Setup

![SLIM 的真实世界、LIBERO/LIBERO-Plus 与 CALVIN ABC→D 评测设置（论文 Figure 4）](https://pic.hana0721.top/blog/paper-deep-dive-slim/experiment-settings.6po8yymyq4.webp)

**【Paper】** LIBERO 包含 Long、Spatial、Object、Goal 四个 suite；LIBERO-Plus 在其上加入相机、初始机器人状态、语言、光照、背景、噪声、布局七类扰动，SLIM 只以原始 LIBERO 数据训练并零样本测试。CALVIN 在 A/B/C 训练环境中训练、在未见的 D 环境中进行最多五条指令的长程组合评测。

**【Paper】** 真实世界为五种任务：胡萝卜入碗、叠三盘、把吐司从烤面包机取出放盘、叠积木、擦白板。每项 150 条示教，共 750 条，多任务混合训练；每个任务—条件组合测试 10 次，并考察 nominal、distractor、lighting、background 四种条件。

**【Paper】** 真实 progress score 的单位也需定义：每次试验只记 0 / 0.5 / 1，分别对应未达里程碑、部分完成、全部完成，再乘 100。例如夹住胡萝卜或吐司只得 0.5、放入碗或放到盘才得 1；白板任务夹起板擦只得 0.5、擦完才得 1；叠三盘先叠两盘为 0.5。每模型共 $5\times4\times10=200$ 次试验，67.8 是这些里程碑分数的均值，绝非 67.8% 完整任务成功率。

### 5.2 Main Results

**【Paper】** 主要数字应按评测协议解读：LIBERO 是成功率，LIBERO-Plus 是对同一 checkpoint 的零样本鲁棒性成功率，而 CALVIN 主指标是平均连续成功指令数，不能与前两者直接相减比较。

| Benchmark / 指标              |               SLIM |                                               论文列出的强对照 |
| ----------------------------- | -----------------: | -------------------------------------------------------------: |
| LIBERO overall success        |              97.5% |                              Fast-WAM 97.6%，OpenVLA-OFT 97.1% |
| LIBERO-Plus zero-shot overall |             77.45% |                              VLA-JEPA 79.5%，OpenVLA-OFT 69.6% |
| CALVIN ABC→D Avg. Length      |          4.556 / 5 |                                   FLOWER 4.53，UnifiedVLA 4.41 |
| 真实世界平均 progress         |               67.8 |                                $\pi_{0.5}$ 56.8，Fast-WAM 40.0 |
| H100 latency / VRAM           | 60.6 ms / 4.26 GiB | $\pi_{0.5}$ 193.1 ms / 7.94 GiB；Fast-WAM 360.6 ms / 13.63 GiB |

**【Paper / Code】** 官方 canonical 记录给出了分母：LIBERO 为 1,950/2,000；LIBERO-Plus 为 7,768/10,030，是按所有测试 case 汇总，不能简单当成七类扰动百分比的等权平均。CALVIN 的 4.556 等于完成至少 1–5 项的概率之和：0.993 + 0.967 + 0.923 + 0.871 + 0.802；完整五项成功率为 80.2%，不是 91.12%。README 说明 CALVIN 发布的是 40-epoch run 中选出的 epoch 15，文章未交代独立 checkpoint-selection split。

**【Analysis】** SLIM 的 LIBERO-Plus 总体 77.45% 仍低于 VLA-JEPA 79.5%，robot initial-state shift 36.90% 也低于其 67.7%。实机 background 下平均 49，低于 $\pi_{0.5}$ 的 54；叠积木两者都只有 10 分。优势是这个模型规模下较高的整体表现与较低推理开销，不能写成所有视觉扰动或所有任务全面领先。不同基线还带有不同预训练、输入及训练配置，排名并未隔离架构的单一因果贡献。

### 5.3 Ablation Study

![Stage 1、IDM:FDM 权重和 EMA target 的消融（论文 Figure 7）](https://pic.hana0721.top/blog/paper-deep-dive-slim/ablation.73uoptv9rr.webp)

**【Paper】** 加上 Stage 1 后，LIBERO-Plus 从约 68.2% 升至 77.45%，CALVIN 从图中约 4.39 升至 4.556；IDM:FDM = 0.125:1 给出最好的联合结果，极端权重更差。

**【Paper】** EMA target 在本实验中是有效的稳定器：没有 EMA 时，LIBERO-Plus 从 77.45% 降至 66.82%，CALVIN 从 4.556 降至 4.382。表征有效秩从 61.28 降至 13.95，而 token cosine similarity 从 0.071 升到 0.352；虽然 future-latent MSE 反而更低（0.245→0.166），论文将其解释为低秩坍塌下更容易拟合的退化 target。

**【Analysis】** Stage 1 消融是整套训练流程的证据，不能直接断言改善只来自未来 loss：Stage 1 还增加 LIBERO-90 数据与计算。官方 direct-policy overlay 写 43 epochs，而 canonical 两阶段是 17,736 + 81,200 optimizer steps；只按 3+40 相加并不自动等于相同更新量、不同目标的 FLOPs 或数据覆盖。Figure 7 没有给误差条，0.125:1 是所测权重中的最佳点；图中 0:1 仅说明去掉 IDM 后变差，并未展示对所有 IDM-only 配方的穷尽比较。

**【Paper】** Figure 8 的 attention 诊断只看两个匹配样例，在第 15 层对 action-to-patch attention 按 action tokens 取最大值，再投影回图像。热图更聚焦物体和夹爪是定性支持，不是因果归因，也不是物体 grounding 的独立准确率。

### 5.4 Generalization

**【Paper】** 泛化证据有三层：LIBERO-Plus 的七类零样本扰动、CALVIN 的未见环境 D 及长程指令组合、真实环境中背景/光照/干扰物变化。它们说明预测 latent 的收益没有仅停留在原始 LIBERO 分布内。

**【Analysis】** 这些证据仍集中于桌面操作和单一模型尺度；它们支持“latent interaction 对这些分布有用”，但尚不足以证明跨机器人形态、开放词汇指令或大规模跨具身数据下仍有相同的 scaling 优势。

## 6. 方法分析

### 6.1 为什么有效？

**【Analysis】** SLIM 将“动作是否合理”转写成两个可学习问题：它是否解释当前到未来的变化（IDM），以及该变化是否能由状态和动作预测（FDM）。这比只从 $o_t$ 做行为克隆提供更密集的结构约束，又不像像素预测那样要求模型分配容量给纹理重建。

**【Analysis】** EMA 缓和 target 的快速漂移；“no EMA” 实现仍然对 online target detach，因此消融比较的是慢速 teacher 与即时 stop-gradient teacher，并非是否阻断 target 梯度。有效秩下降、相似度与能量集中上升支持退化解释，但 EMA 本身不是避免任何形式坍塌的数学保证；两个不同 target 分布的 MSE 也不能单独拿来衡量预测质量。

### 6.2 核心创新

**【Paper】** 创新不是“使用 flow matching”本身，也不是单独使用 future latent，而是将 inverse/forward masked prediction 放入部署时同一 MoT，并让 Stage 2 用 future slots 替代真实未来 latent。由此，训练时显式注入 dynamics，推理时仍保持当前观测到动作的短路径。

### 6.3 与已有方法的本质区别

| 路线         | 主要表征 / 推理负担                                 | SLIM 的差异                                                         |
| ------------ | --------------------------------------------------- | ------------------------------------------------------------------- |
| 大型 VLA     | 大 VLM 主导每步控制                                 | 将主干换成紧凑 observation-action interaction，语言为条件而非主序列 |
| 像素级 WAM   | 预测 future frame/video，可能 test-time imagination | 仅训练期预测 latent；部署不生成未来视觉                             |
| JEPA 式预测  | embedding prediction                                | 加入 action reconstruction，使 future latent 受到动作重建的统计约束 |
| 分离 IDM/FDM | 两个模块或表征空间                                  | 两个目标共享同一个 MoT policy backbone                              |

### 6.4 关键假设

**【Analysis】** 方法假设 DINOv2 latent 中已含有足够的可控视觉因素，且“$H$ 步后的 latent”是一个合适的预测粒度。若关键接触状态难以从 RGB latent 识别，或动作后果高度随机，FDM 目标可能不再是好的控制表征监督。

## 7. 局限性

### 7.1 作者明确提出的局限

**【Paper】** 实验只覆盖一个紧凑模型规模，尚未建立该范式如何随模型容量、预训练数据规模和 embodiment diversity 扩展。作者将跨具身轨迹上的 scaling 视为后续方向。

### 7.2 自己分析得到的局限

**【Analysis】**

1. FDM 只预测固定 horizon 的 latent，无法显式提供长期规划所需的多步分支或不确定性；长程能力主要仍依赖闭环反复执行。
2. Table 4 / Appendix A.5 测的是单张 H100、batch=1、BF16、PyTorch eager 的模型调用，排除环境、RPC、模型加载；SLIM / Fast-WAM 缓存语言，$\pi_{0.5}$ 走原生 PyTorch 路径。三者分别预测 8 / 32 / 10 步并采样 4 / 10 / 10 次，490.73 / 2090.07 / 4714.59 GFLOPs 是每 chunk 而非每控制步。60.6 ms 约为每秒 16.5 次模型调用，不是完整闭环频率；4.26 GiB 为论文定义的增量峰值，不宜作为包含所有服务常驻项的总显存承诺。
3. 使用 DINOv2 与 T5-small 仍带有外部预训练先验；“无 additional embodied pretraining”不应被误读为“从头学视觉与语言”。
4. Stage 1 需要同一轨迹的 future observation；这在离线示教数据中自然成立，但并不能直接解决在线环境下的因果探索与数据覆盖问题。

## 8. 启发与研究思考

**【Analysis】** SLIM 说明 world-model 思想不必等同于“在推理时生成世界”。对控制而言，更关键的是将动作后果写入 policy 的内部表征。一个值得继续验证的方向是：将 FDM target 从单一未来时刻扩展为多尺度、带不确定性的 predictive slots，再用规划或 value learning 选择 action chunk。

**【Analysis】** 另一个研究问题是动作可辨识性：如果多个动作导致视觉上相似的未来，IDM 会遭遇天然多模态。可在 future latent 外引入力觉、末端位姿或接触事件，并让模型显式预测分布而非点目标；这可能比一味放大 VLM 更直接改善精细操作。
