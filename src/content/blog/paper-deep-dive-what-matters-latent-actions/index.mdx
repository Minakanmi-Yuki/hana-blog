本文依据 [arXiv v1 全文](https://arxiv.org/pdf/2608.19613v1)（2026-08-20，16 页，含 Table III，无另列附录）核对。下面区分论文的设计建议与表格实际支持的结论，尤其注意动作监督是否可用、数据域和成功率的统计单位。

### 一句话总结

**【Paper】** 论文把 latent action learning 统一成可比较的 autoencoding 框架，系统评估 latent-action 建模范式、正则化、动作头、维度、归一化和数据规模，回答“哪些设计真正改善机器人控制”，而不是只报告某一个方法的孤立结果。

### 核心贡献

**【Paper】** 研究覆盖 41 个去重后的设计选择、三个 benchmark（LIBERO、LIBERO-Plus、RoboTwin2.0）和 Franka Panda 真实实验，主要结论是：

1. 原始 LAPO（IDM-FDM）在直接使用 raw video 时仍是最强基线之一；$\Delta$DINO 这种简单的语义特征差分也很有竞争力。
2. 连续正则化方法的类型差异小于正则化强度差异；VAE 是默认首选，VQ-VAE 在本研究的 LIBERO-Plus RobotInit 评测上更有优势，不能推广为所有分布外扰动。
3. latent action 维度 32 在 7-DoF 单臂和 14-DoF 双臂之间取得最稳健的折中；已有合适正则时，多数组合无需额外归一化，但仍有例外。
4. FDM 重建指标比训练 probe 解码 physical action 更能预测下游表现，但只适合粗粒度筛选。
5. 用 latent action 微调 VLM backbone，且扩大 Stage-II 视频规模，在所测两种数据规模与真实任务中改善下游表现；这不是已经拟合出的普适 scaling law。

## 2. 背景与相关工作

**【Paper】** VLA 需要把视觉、语言和 physical action 对齐，但机器人 action data 的规模远小于互联网图像/视频。Latent Action Model（LAM）试图从无标注视频的相邻帧中提取紧凑的 $z_t$，把“状态如何变化”作为 physical action 的替代监督，从而把海量 video-only data 接入机器人学习。

已有方法大致分两类：

- **IDM-FDM**：Inverse Dynamics Model 从 $(o_t,o_{t+1})$ 推断 $z_t$，Forward Dynamics Model 再用 $(o_t,z_t)$ 重建未来帧，代表是 LAPO、LAOF、CoMo。
- **CFD-AE**：先计算 $\Delta$RGB、$\Delta$DINO 或 optical flow，再用 Encoder/Decoder 压缩和重建差分。

**【Analysis】** 过去工作往往只改一个模块、换一套数据和 action head，导致“方法更好”与“实验配方更好”混在一起。这篇论文的价值不在于提出全新的 LAM，而在于把这些选择放到同一坐标系中，测量它们对 downstream policy 的真实影响。

## 3. 问题定义

**【Paper】** 在时间 $t$，机器人观察图像 $o_t$，执行 physical action $a_t\in\mathbb{R}^{d_a}$ 并到达 $o_{t+1}$。LAM 学习低维 latent action $z_t\in\mathbb{R}^{d_z}$，使其包含从当前帧到未来帧的 transition information。**【Analysis】** 这里 $z_t$ 是观察到的变化的编码，不是有物理单位的关节命令：物体运动、相机变化、接触和机器人动作都可能影响它，单靠重建目标不会保证动作因素被唯一识别。

轨迹可写成：

$$
\tau=(o_t,a_t,z_t,o_{t+1},l)_{t=1}^{T},
$$

其中 $l$ 是语言指令。训练分为三阶段：

| 阶段                    | 数据                          | 目标                                  | 是否需要 physical action             |
| ----------------------- | ----------------------------- | ------------------------------------- | ------------------------------------ |
| Stage I Pre-training    | 无标注视频帧                  | 学习 LAM 与 transition representation | 否                                   |
| Stage II Mid-training   | 语言标注视频 + 自动生成 $z_t$ | 用 latent action 微调 VLM backbone    | DAP/LAP 不需要；JAP 另用联合监督协议 |
| Stage III Post-training | 机器人示教 $(o_t,a_t,l)$      | 学 physical-action policy             | 是                                   |

**【Paper】** Stage I 使用 700M spatiotemporal Transformer，随机时间下采样因子来自 $\{1,2,3,4,5\}$，帧被 center-crop 到 $224\times224$；Stage II/III 在 StarVLA 实现框架内使用 Qwen3-VL-4B 与 OpenVLA-OFT 配方，因此这里的 baseline 是本文重建的 Qwen3-VL 版本，不能直接与其他论文的原始 OpenVLA-OFT 数字混比。

## 4. 方法

### 4.1 Overall Architecture

![论文 Figure 2：LAPO、LAOF、CoMo 与 CFD-AE 的统一比较](https://pic.hana0721.top/blog/paper-deep-dive-what-matters-latent-actions/cfm.7i14gjov4h.webp)

**【Paper】** 统一数据流是：相邻观测进入 LAM 得到 $z_t$；Stage-II 用 $(o_t,z_t,l)$ 微调 VLM；Stage-III 再把 VLM 表征接到 physical-action head。IDM-FDM 通过未来帧重建学习隐式 transition，CFD-AE 则直接重建预定义的帧差分。

### 4.2 核心模块

#### Latent-action modeling

- **LAPO**：$z_t=\mathrm{IDM}(o_t,o_{t+1})$，$\hat o_{t+1}=\mathrm{FDM}(o_t,z_t)$。优点是无需额外预处理，直接从 raw frames 学习。
- **LAOF**：在 LAPO 的未来帧重建外，再由 FlowDecoder 重建 optical flow，目标包含帧重建与光流重建两项。另两条 RAFT、SEA-RAFT 基线则属于 CFD-AE：压缩光流本身，不能与 LAOF 的辅助光流监督混同。
- **CoMo**：IDM 接收当前帧与 $\Delta$DINO，FDM 仍重建未来帧；用语义差分限制直接复制未来外观的 shortcut。差分仍由未来帧计算，不能理解为训练时完全不接触未来信息。
- **CFD-AE**：$z_t=\mathrm{Encoder}(\Delta_t)$，$\hat{\Delta}_t=\mathrm{Decoder}(z_t)$，其中 $\Delta_t$ 可为 $\Delta$RGB、$\Delta$DINO 或 optical flow。

**【Paper】** Design I 固定 $d_z=64$、正则系数 $10^{-6}$，在统一训练与评测框架内比较上述七项选择。**【Analysis】** 这提高了比较的可解释性，但不等于严格等计算预算：光流估计、DINO 特征和附加 decoder 各有开销，论文没有给出所有变体的端到端算力配平表。

#### 正则化

**【Paper】** 总目标为 $\mathcal{L}=\mathcal{L}_{method}+\lambda_{reg}\mathcal{L}_{reg}$，比较 AE、VQ-VAE、VAE、Sparsity 和 SIGReg：

| 方法     | latent 约束                       | 直觉                                                          |
| -------- | --------------------------------- | ------------------------------------------------------------- |
| AE       | 无额外约束                        | 只优化重建，可能利用 shortcut；不保证实测重建最优             |
| VQ-VAE   | 最近邻 codebook + commitment loss | 限制可用编码集合；是否形成可复用动作原语仍需验证              |
| VAE      | KL 到 $\mathcal{N}(0,I)$          | 连续、平滑、可采样                                            |
| Sparsity | VCM + $\ell_1/\ell_2$             | 少量维度激活、降低冗余                                        |
| SIGReg   | 随机投影的一维分布匹配高斯        | 鼓励各向同性并抑制 collapse，不保证有限投影已识别完整联合分布 |

#### Latent action integration

**【Paper】** 给定 $h_t=\mathrm{VLM}_{\psi}(o_t,l)$，五种方案同时改变信息路径和训练协议（§IV-C）：

| 方案              | backbone 与动作头如何训练                                                                             | 部署时物理动作的来源                      |
| ----------------- | ----------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| DAP               | Stage II 学 $h\to z$；Stage III 丢弃 latent head，新接物理动作头                                      | $h\to a$                                  |
| LAP               | Stage II 学 $h\to z$；Stage III 保留该头，再接物理动作 decoder，backbone 与两头一起用物理动作损失更新 | $h\to\hat z\to a$                         |
| JAP               | 跳过单独的 Stage II，在 Stage III 联合预测 latent 和物理动作；两类数据贡献各自损失                    | $h\to[\hat z,a]$，物理输出不经过 $\hat z$ |
| JAP-DAP / JAP-LAP | 先按 JAP 联合微调，再丢弃已训练的动作头，重新训练 DAP 或 LAP 头                                       | 分别为直接预测或 latent bottleneck 路径   |

**【Analysis】** 因而 JAP 与 DAP/LAP 的差异不只是 head 形状，还包括 physical-action 标签参与 backbone 学习的时机。LAP 保留 latent 的计算路径，却不等于 Stage III 继续用 latent 标签约束这个中间量：论文此阶段用的是 $\mathcal L_{act}$，中间表示可随控制目标改变。JAP-DAP/LAP 用于检查联合监督留下的初始化收益，也不是“只换 head、其他训练完全相同”的无条件对照。

![论文 Figure 4：不同 action head 的跨 benchmark 平均性能](https://pic.hana0721.top/blog/paper-deep-dive-what-matters-latent-actions/actionhead.232ly48iyn.webp)

### 4.3 关键公式

**LAPO 重建：**

$$
z_t=\mathrm{IDM}(o_t,o_{t+1}),\qquad \hat{o}_{t+1}=\mathrm{FDM}(o_t,z_t),
$$

$$
\mathcal{L}_{recon}=\lVert o_{t+1}-\hat{o}_{t+1}\rVert_2^2.
$$

其中 $z_t$ 是需要被压缩的 transition code，$\hat{o}_{t+1}$ 是 FDM 的预测帧；该损失要求 latent action 与当前帧共同解释状态变化，但不会区分变化是机器人造成的还是外部扰动造成的。大容量 latent 还可能把未来帧信息直接传给 FDM，因此好重建不自动等于好控制。

**VAE 正则：**

$$
\mathcal{L}_{reg}^{VAE}=D_{KL}\big(p_{IDM}(z_t|o_t,o_{t+1})\,\|\,\mathcal{N}(0,I)\big).
$$

**【Analysis】** $\lambda_{reg}$ 决定“保留 transition 信息”和“限制 latent 容量”的平衡；过大时 latent 过于规整，FDM 反而无法重建真实变化。

**Physical-action 训练：**

$$
\mathcal{L}_{latent}=\lVert z_t-\hat z_t\rVert_2^2,\qquad
\mathcal{L}_{act}=\lVert a_t-\hat a_t\rVert_2^2.
$$

JAP 使用 $\mathcal{L}_{latent}+\mathcal{L}_{act}$，DAP/LAP 在各自阶段使用对应分支的损失。

### 4.4 Training

**【Paper】** 完整 video-only corpus 约 5,900 万帧，包括 OXE 子集、Robotwin 与 Liberoplus；“video-only”表示这些阶段不读取物理动作标签，并不表示视频来自无关的互联网场景。§V-A 将完整混合作为默认数据，并说明大规模 Design I–III 消融在 Robotwin 与 Liberoplus 数据上开展。Stage I、II 名义训练步数均为 150k；Stage II 使用 LAM 自动标注的 latent 监督 VLM。

**【Paper】** Stage III 的 LIBERO/Plus 路线使用 **LIBERO 的动作标签**后训练，再在 LIBERO-Plus RobotInit 上评测；不能写成使用 LIBERO-Plus 动作标签训练。RoboTwin 的动作训练集来自全部 50 个任务，评测受算力限制选 12 个任务。Table III 中 Stage-II chunk 为 1，Stage-III 的 LIBERO chunk 为 8、RoboTwin/真实机器人为 50，因此表征学习的帧间变化与部署的动作块不是同一个时间单位。

**【Analysis】** Stage I/II 数据清单本身包含 Liberoplus。作者的 zero-shot 首先应按“没有使用 LIBERO-Plus 物理动作标签做后训练”理解；正文没有充分列出这些视频与 RobotInit 测试场景的拆分，不能进一步宣称模型从未见过目标域的任何视频。

## 5. 实验

### 5.1 Experimental Setup

**【Paper】** LIBERO 是 7-DoF 单臂 end-effector delta control；LIBERO-Plus 在相同任务上加入 RobotInit 等扰动，本文报告最具挑战的 RobotInit；RoboTwin2.0 是 14-DoF 双臂 joint-position control，选取 12 个任务。每个消融通常汇报 3 个随机种子的平均成功率。

![论文 Figure 5：四种 latent-action proxy metric 与下游性能的相关性](https://pic.hana0721.top/blog/paper-deep-dive-what-matters-latent-actions/metrics.8adzya5h2c.webp)

**【Paper】** Linear probe 为 $[d_z,d_a]$，MLP probe 为 $[d_z,128,128,d_a]$，统一只训练 50 步、batch 256、学习率 $10^{-3}$。用负损失表示分数，数值越大越好；因此它们测的是一个固定且很短的解码预算下动作有多易恢复，不能视为 latent 中全部可恢复信息的上界。

FDM 的增益以“直接复制当前帧”为参照。例如

$$
G_{\mathrm{MSE}}=1-
\frac{\mathrm{MSE}(o_{t+1},\hat o_{t+1})}
{\mathrm{MSE}(o_t,o_{t+1})}.
$$

$G=0$ 表示与复制持平，$G<0$ 表示更差，$G=1$ 表示完美重建；这不是成功率，也不保证落在 $[0,1]$。静止帧使分母接近零，论文未披露数值稳定处理。SSIM Gain 使用同样的“相对复制基线改善”思路。Fig. 5 先比较 21 个正则配置，再加入 8 个维度配置，总计 29 个；这些 proxy 不是对全部 41 项选择都完成了独立验证。

### 5.2 Main Results

**【Paper】** Table II 先对五种动作整合方案平均，再对三个 benchmark 等权平均，得到七种建模范式的排序（并非把所有 rollout 合并计数）： LAPO 0.7327 > $\Delta$DINO 0.7280 > CoMo 0.7167 > $\Delta$RGB 0.6973 > LAOF 0.6907 > SEA-RAFT 0.6433 > RAFT 0.6427。LAPO 不需要 optical-flow 预处理，说明简单的 raw-frame IDM-FDM 仍然是强基线；$\Delta$DINO 接近 LAPO，表明预训练语义空间本身提供了有效归纳偏置。

**【Analysis】** 光流路线在这套配置下较弱，作者推测是像素位移约束丢失部分遮挡、接触等视觉线索，且流估计误差会传播。但这些实验没有独立识别两种原因的贡献，也不证明光流普遍无用。尤其正文虽讨论 LIBERO-Plus 的 Noise 扰动，主评测协议实际是 **RobotInit**；不能把这张表的降分直接归因于 Noise 测试。

### 5.3 Ablation Study

**【Paper】** Design II 固定 LAPO、$d_z=64$。Fig. 3 用 SSIM Gain + MSE Gain − MLP loss − Linear loss 的组合指标选正则强度，得到 VAE $10^{-7}$、Sparsity $10^{-5}$、SIGReg $10^{-3}$、VQ-VAE 1。Table II 的 VQ-VAE 在 RobotInit 上五种动作头平均为 0.517，高于 AE 0.445、VAE 0.433、Sparsity 0.468、SIGReg 0.467；但其 RoboTwin 平均为 0.821，低于 AE 的 0.852 和 VAE 的 0.859。

**【Analysis】** 这些系数不是与实现无关的常数：损失的 sum/mean、latent 维度与 batch 统计都会改变有效正则力度。VQ 的泛化收益与连续控制精度存在实测取舍；“离散编码学到了可复用原语”是可能解释，并没有由这张成功率表直接证明。

![论文 Figure 7：latent action 维度对三个 benchmark 的影响](https://pic.hana0721.top/blog/paper-deep-dive-what-matters-latent-actions/latentdims.1hsybtf9py.webp)

**【Paper】** §V-D 推荐无物理标签时用 LAP、有标签时用 JAP-LAP；但 Fig. 4 **不支持无例外的动作头排序**。以下为三个 benchmark 的等权平均：

| 表征         | DAP   | LAP   | JAP   | JAP-LAP |
| ------------ | ----- | ----- | ----- | ------- |
| $\Delta$DINO | 0.749 | 0.752 | 0.709 | 0.719   |
| LAOF         | 0.687 | 0.656 | 0.698 | 0.708   |
| VQ-VAE       | 0.756 | 0.747 | 0.743 | 0.758   |

**【Analysis】** $\Delta$DINO 仅用 latent 监督进行中训练的两条路线强于联合路线；LAOF 的 LAP 低于 DAP；VQ 的 DAP 也高于 LAP。因此真正有用的结论是 **表征与整合方式需要配对选择**。联合监督可能塑造更适合控制的 backbone，但这里改变了监督访问权限与训练协议，不能把所有增益归给某种网络连线。

### 5.4 Generalization

**【Paper】** Fig. 7 固定 LAPO + VAE($10^{-6}$)，只平均 DAP/LAP；$d_z=32$ 是所测控制设置间的折中：LIBERO 上 $d_z=16$ 得到 0.926、$d_z=32$ 为 0.922；LIBERO-Plus 上 $d_z=8$ 为 0.526、$d_z=32$ 为 0.516；RoboTwin2.0 上 $d_z=32$ 达到 0.856，明显高于 $d_z=8$ 的 0.802。适当正则化后不归一化 latent action 更好，33 个方法与 benchmark 组合中 28 个受益，平均提升 1.15 个百分点，故仍有 5 个组合不支持这一选择。这里不是把一个策略直接零样本迁移到新 embodiment，而是在各控制任务上分别训练和比较。

**【Paper】** Fig. 9 将 Stage-II 数据从 Robotwin+Liberoplus（完整数据的 14.5%）扩至加入 OXE 的约 59M 帧，并固定 Stage-III 配方。LIBERO-Plus 的 LAP 从 0.488 到 0.578，增加 **9.0 个百分点**；DAP 从 0.477 到 0.547，增加 7.0 个百分点，另外两个 benchmark 也改善。**【Analysis】** 这是两个规模点的正向趋势，同时加入了新的真实机器人数据域，无法把数量和多样性效果完全分离，也不足以拟合幂律或预测继续扩大数据的收益。

![论文 Figure 10：Franka Panda 真实机器人任务与 LA-Tuned 对比](https://pic.hana0721.top/blog/paper-deep-dive-what-matters-latent-actions/realworld.6po8yt89su.webp)

**【Paper】** 真实机器人共同使用四个任务的 200 条示教（每任务 50 条）。LA-Tuned 用 LAPO + VAE($10^{-7}$)、$d_z=32$、不归一化 latent 微调 backbone，部署采用 **DAP**，以隔离初始化的作用。

Fig. 10 在 6k、8k、10k、20k、40k 五个检查点评测，每个检查点每任务 20 次，因此每种方法的总计是 $5\times4\times20=400$ 次。317/400 与 259/400 对应 **整段学习过程的汇总** 79.25% 与 64.75%，不是最终检查点各测试 400 次。10k 时 LA-Tuned 的 85.0% 对比 baseline 40k 的 76.25%，分别来自该检查点四任务合计 80 次测试。两者动作示教数量相同，这说明后训练步数效率更好，不能表述为减少了四倍示教或全流程训练成本。

**【Analysis】** 真实实验支持的是 latent 监督改善 backbone 初始化，因为最终用的是 DAP，并不验证“必须保留 latent bottleneck 或采用 JAP”。Table III 另列真实训练 150k 步，而 Fig. 10 只给出到 40k 的曲线，不能将汇总值当成未展示的 150k 最终成绩。

## 6. 方法分析

### 6.1 为什么有效？

**【Analysis】** latent action 的有效性来自三个互补因素：第一，FDM 重建迫使 representation 关注可预测的状态转移；第二，VLM backbone 在大规模视频上获得 motion-aware visual features；第三，LAP/JAP 把这些 features 与 physical control 保持结构化连接。它不是把 latent 当作“更短的 action token”，而是把 latent 当作视觉表征到控制之间的中间坐标系。

### 6.2 核心创新

**【Paper】** 论文的创新主要是实验方法论：统一 autoencoding 框架、跨 41 项选择的 controlled study、代理指标相关性分析以及扩大 Stage-II 数据后的趋势。41 项是去重的设计选择，并非所有因素完整笛卡尔积的 41 个互相独立模型。与提出一个新网络相比，这种系统基准更适合指导后续 LAM 工程取舍。

### 6.3 与已有方法的本质区别

**【Analysis】** 传统 LAM 论文常围绕单一正则或动作头证明有效；本文把“latent 如何学”“latent 如何接入 policy”“如何评价 latent”拆成三个正交问题，并显示强基线、超参数和训练阶段耦合关系。结论因此更像设计准则，而非一个不可替换的模型配方。

### 6.4 关键假设

**【Paper】** 主要假设包括：相邻帧足以提供可学习的 transition signal；自动生成的 latent action 可以作为 VLM 的稳定监督；video-only 表征的提升能迁移到 physical action policy。**【Analysis】** 当前实验在 front-view、有限任务和固定控制接口下支持这些假设，但不代表所有机器人 embodiment 或长时程任务都成立。

## 7. 局限性

### 7.1 作者明确提出的局限

**【Paper】** §VI 明确把真正的互联网野外视频、更广泛的机器人形态，以及将 latent action 纳入基础模型从头预训练列为未来工作；现有训练数据仍是机器人数据集。另在 §V-E 强调 proxy metric 不能取代完整 downstream evaluation：Pearson 相关性较高，但 Spearman 相关性明显较低，因此只能做粗粒度筛选，不能可靠地给模型排序。跨 latent dimension 比较时，所有 proxy 的相关性还会下降。

### 7.2 自己分析得到的局限

**【Analysis】** 所有变体仅用 front-view、无 proprioception 和数据增强，便于隔离变量，却也限制了结论对更强部署配方的适用性。论文使用 8×H200，但没有完整报告各变体总 GPU 时数；不能只据显卡数量换算训练成本。三种子均值缺少足够的逐配置方差信息，小幅差距不宜当作统计上已确定的排名；短预算 probe 还受动作单位、维度与 decoder 优化影响，LIBERO 与 RoboTwin 的 probe 损失不能单凭数值跨控制接口比较。

## 8. 启发与研究思考

1. **先选强基线，再调正则强度。** LAPO + VAE($10^{-7}$) + $d_z=32$ 是合理起点，避免一开始堆叠复杂 optical-flow 或稀疏正则。
2. **同时比较 DAP 与保留 latent 的路线。** 有动作标签时加入 JAP/JAP-LAP，但检查标签预算与训练步骤；表征不同，最优动作头也可能不同，真实实验本身已表明 DAP 可以受益。
3. **代理指标应按同一维度使用。** FDM 的 SSIM/MSE Gain 更贴近 transition，但最终模型选择仍必须回到真实任务成功率。
4. **分别控制数据数量和数据多样性。** 当前两点实验同时引入 OXE 新数据域，值得继续用多档规模与固定混合比例检验收益来源。
5. **值得继续研究的方向**：从单帧 latent action 走向 history-aware latent、把接触/力觉纳入 transition supervision，以及设计能跨 action dimension 校准的 proxy metric。
