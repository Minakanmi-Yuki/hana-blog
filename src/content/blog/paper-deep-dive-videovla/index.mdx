## 1. 论文概述

**论文名称**：《VideoVLA: Video Generators Can Be Generalizable Robot Manipulators》

**作者**：Yichao Shen、Fangyun Wei、Zhiying Du、Yaobo Liang、Yan Lu、Jiaolong Yang、Nanning Zheng、Baining Guo

**机构**：西安交通大学、Microsoft Research Asia、复旦大学

**会议**：NeurIPS 2025

**论文 / 代码 / 项目**：[arXiv](https://arxiv.org/abs/2512.06963) · [官方代码](https://github.com/VideoVLA-Project/VideoVLA) · [项目主页](https://videovla-nips2025.github.io/)

本文核对 [arXiv v1 正文及附录 A–D](https://arxiv.org/html/2512.06963v1)，与[官方代码 commit 05b5cca](https://github.com/VideoVLA-Project/VideoVLA/tree/05b5cca7d4ec32e786b7e10dcbfbf5926637b293)。代码分析为静态核验，未运行大模型或机器人实验。

### 一句话总结

**【Paper】** VideoVLA 不把视频生成仅当作可视化副产品：给定当前图像和语言指令，它在一个多模态 Diffusion Transformer 中**联合预测未来视频 latent 和将要执行的动作 chunk**，借由二者在每一次去噪中的耦合，把预训练视频模型的条件理解、未来演化与物理先验迁移为机器人操控的泛化能力。

### 核心贡献

**【Paper】**

1. 将 CogVideoX 的 Video DiT 扩展为 Video-Action DiT：视频、语言与连续动作在一个统一 token 序列中交互。
2. 提出 dual-prediction：对未来视觉结果和动作同时施加 DDPM 去噪监督，而不是只学习动作。
3. 在 SIMPLER 和 Realman 真实机器人上测试 in-domain、新物体、跨 embodiment 新技能三类能力，并报告优于所列基线的总体结果。
4. 分析视觉想象与执行结果的相关性：高质量 imagined future 与更可靠的动作、较高的任务成功率相关。

**【Analysis】** 论文的关键转向不是“在 VLA 旁边再生成一段视频”，而是要求 action token 与 future-video token 在同一生成过程里彼此解释。更精确地说，它学习 $p(A,V_{future}\mid I_t,\ell)$ 的联合分布，在示教中同时拟合动作及其视觉伴随结果。训练没有对同一状态主动干预不同动作，也没有额外的因果一致性判别器，因此不宜把它称为已经验证的“反事实约束”。

## 2. 背景与相关工作

**【Paper】** 常见 VLA 主要从视觉、视觉语言或语言理解模型迁移能力，再在机器人数据上微调。它们能读懂指令、识别物体，但面对未见物体、未见任务或未见环境时，泛化仍有限。另一边，大型视频生成器在新文本/新图像条件下生成连贯未来的能力，包含物体外观、运动与部分物理动态先验。

**【Paper】** VideoVLA 的出发点是两类条件生成问题的结构相似性：视频模型根据文本和首帧预测未来世界，操控策略根据语言和当前观测预测未来行为。前者的“未来”尚没有可执行动作，后者的动作也未必被显式约束其视觉后果；论文用联合生成弥合这个缺口。

**【Analysis】** 相比把视频生成器作为高层 planner、再由另一个 policy 跟踪计划，VideoVLA 的耦合更紧：它只训练一个联合生成器（仍有 T5 与 VAE 编码器）。论文默认未实现候选视频/动作评分与筛选；从联合模型采多组候选在原理上并非不可能。其设计特点是 action 和 video 能在扩散的每个时间步交换信息，而不是只在两个模块接口处相接。

## 3. 问题定义

**【Paper】** 给定语言指令 $\mathcal{T}$ 与当前视觉观测 $\mathcal{O}$，策略要同时输出：

$$
\mathcal{A}=\{\boldsymbol{a}_i\in\mathbb{R}^{7}\}_{i=1}^{K},\qquad
\mathcal{F}=\{\boldsymbol{F}_j\}_{j=1}^{N}.
$$

- $\mathcal{A}$ 是 action chunk。每步 7 维：前三维腕部旋转、接着三维腕部平移、最后一维夹爪二值状态（0 闭合、1 张开）。
- $\mathcal{F}$ 是执行该 chunk 后预期看到的未来视频。模型实际预测其 latent，而非 RGB 像素。
- 每次执行一个 chunk 后获取新观测，再重复预测；动作频率和视频帧频率可以不同。

**【Paper】** 预训练使用 OXE（Open X-Embodiment）中与前作相同的子集：约 2,250 万帧。60 个数据集、22 类 embodiment 是 OXE 总体介绍，论文未给出所用子集逐数据集清单，不能直接把总体覆盖算作实际训练混合；真实实验另采集 5,824 个 Realman 样本，覆盖 pick、stack、place 三项任务。

| Embodied AI 项目      | VideoVLA 的选择                                         |
| --------------------- | ------------------------------------------------------- |
| Observation           | 当前单帧图像，经 3D-causal VAE 编为首帧 latent          |
| Language              | T5 编码为固定 226 个 token                              |
| Action representation | 不离散化的连续 7D action；一次预测 6 步（论文默认实验） |
| Future representation | CogVideoX 3D-causal VAE 的 future-frame latent          |
| Policy / decoder      | 预训练 CogVideoX-5B 初始化的多模态 DiT                  |
| Deployment            | 每轮只执行预测 6 步动作中的前 3 步，然后重新观测        |

**【Paper】** 架构由两类 encoder 和一个 DiT backbone 构成：T5 把指令变成文本 token；CogVideoX 的 3D-causal VAE 把训练视频变成 latent；DiT 以文本 token 和当前首帧 latent 为条件，联合生成 future-frame latents 与 action chunk。粉色 VAE decoder 只在展示 imagined future 时使用，并不参与机器人控制输出。

**【Paper】** 一句话数据流：`instruction + current-image latent → unified DiT → future-video latents + action chunk`；训练与运行时分别如何构造/去噪，在 4.4 与 4.5 展开。

### 4.2 核心模块

#### 条件编码：T5 与 3D-causal VAE

**【Paper】** T5 将 $\mathcal{T}$ 编为 226 个 token $\boldsymbol{T}$。3D-causal VAE 将视频 $\mathcal{F}$ 编为 $\mathcal{V}=\{\boldsymbol{V}_j\}_{j=1}^{n}$；因其因果性，$\boldsymbol{V}_1$ 只编码首帧，恰好可作为当前观测 $\mathcal{O}$ 的表示。训练时编码完整视频获得首帧和未来 latent；推理时只编码当前图像以获得 $\boldsymbol{V}_1$。

#### Unified Video-Action DiT

**【Paper】** 模型以 raster order 展平当前/未来视觉 latent，拼接文本 $\boldsymbol{T}$、当前图像 $\boldsymbol{V}'_1$、带噪未来 latent $\{\boldsymbol{V}'_j\}_{j=2}^{n}$ 与带噪动作 $\mathcal{A}$。所有模态投影至共同 embedding dimension 后，经 self-attention 在时间和模态之间交互；扩散 timestep 用 adaptive LayerNorm 注入。

**【Paper】** 这让模型不是先“生成视频、再由视频取动作”，也不是并排的两个 head：future-video token 与 action token 在相同 DiT block 中共同去噪。论文还比较同步与异步 schedule，默认同步训练、同步推理的 SIMPLER 平均成功率为 80.4%，高于异步训练/同步推理的 73.8% 和异步训练/异步推理的 71.0%。

#### 双预测为何是必要约束

**【Paper】** 消融中，完整 dual-prediction 在 Google Robot 的 SIMPLER in-domain 三任务均值为 80.4%；只去掉 video loss 降至 27.0%，只预测 action 降至 25.5%。在新物体 / 新技能泛化上，完整模型为 65.2% / 48.6%，`No video loss` 为 12.7% / 4.4%，`Action only` 为 11.3% / 2.1%。

**【Analysis】** 这份消融支持“视频损失很重要”，但不单独证明提升完全来自视频模型的物理常识：同时损失也增加了预测目标、提供了稠密的时间监督。它证明的是这种联训设定有效，不等价于对每个动作都进行了显式的 model-predictive verification。

### 4.3 关键公式

**【Paper】** 论文说明两模态使用 DDPM 去噪损失，但没有在正文固定一个“网络原始输出必为 epsilon”的完整公式。为了与公开实现对应，令 $x_t=\alpha_t x_0+\sigma_t\epsilon$、$\alpha_t^2+\sigma_t^2=1$；对视频与动作分别预测 velocity $v_t=\alpha_t\epsilon-\sigma_t x_0$，可写成：

$$
\mathcal{L}_{\mathrm{dual}}
=\lambda_v\,\mathrm{mean}\|\hat v_v-v_v\|^2
+\lambda_a\,\mathrm{mean}\|\hat v_a-v_a\|^2.
$$

**【Code】** `VideoScaling` 与 `DiscreteDenoiser_withact` 将网络输出转为 $\hat x_0=\alpha_t x_t-\sigma_t\hat v$；loss 实际计算 $\|\hat x_0-x_0\|^2/\sigma_t^2$，代入后等价于上面的 v-prediction MSE。变量名 `action_pred_noise` 不能单独证明它是 epsilon prediction；若照原博客的噪声公式对接网络，会弄错目标。

**【Code】** 视频、动作各自采独立高斯噪声，但共享 diffusion timestep；同步不等于使用同一份噪声。两项分别对自身元素求 mean，再以 `vd_lw=act_lw=1` 相加，故视频 token 多不意味着按总元素数自动压倒动作损失。论文概念图将当前首帧作为条件，公开 image-to-video 路径则将首帧 latent 加零填充后作为额外 channel concat；这应与待去噪的视频张量区分。

### 4.4 Training

**【Paper】** 论文采用 CogVideoX-5B 初始化，预训练 100K iterations、微调 15K iterations，使用 32 张 AMD MI300X、batch size 256、AdamW（learning rate $10^{-5}$，weight decay $10^{-4}$）。仿真使用 49 帧/13 个视频 latent 的长度配置，真实机器人使用 13 帧/4 latent。按论文 causal VAE 定义，首个 latent 对应当前帧，因此严格说分别含 12/3 个未来 latent；作者把整段简称 future latents，不能据此再额外加一个首帧。两种情形均预测 6 个动作。

### 4.5 Inference

**【Paper】** 每轮推理只输入当前观测：编码首帧后，模型从噪声中同时去噪出视频 latent 和 6 步动作；部署时只执行前 3 步，获取新图像后再次调用策略。正文默认 50 个 DDIM denoising steps；附录 D 的真实部署效率配置使用 4 latent、10 steps，单张 H100 一次约 1.1 秒。作者称约 3 Hz，来自每次执行 3 个动作的有效输出量级；串行重规划本身至多约 $1/1.1=0.91$ 次/秒，且还未计入其他执行开销，不能称为 3 Hz 视觉闭环。正文没有逐表明确切换 50/10 步，本文不替作者推定每张表的精确 sampler 配置。

## 5. 实验

### 5.1 Experimental Setup

**【Paper】** 仿真使用 SIMPLER：WidowX 在 Visual Matching（VM）下评 4 个任务；Google Robot 在 VM 与 Variant Aggregation（VA）下评 Pick Up Coke Can、Move Near、Open/Close Drawer、Open and Place。VA 会改变背景、光照和桌面纹理。比较使用 OXE 训练的模型；$\pi_0$ 在该表特意去掉 proprioception，仅保留视觉输入，故其分数不能代表带本体状态的标准配置。Appendix A 给 Google-VM 四任务 300/240/216/108 次，VA 为 825/600/378/189 次，WidowX 每任务 24 次。

**【Paper】** 真实实验用配有 7-DoF 手臂与夹爪的 Realman；论文采集 5,824 个 pick、stack、place 样本，并对预训练模型进行微调。真实新物体测试使用 12 个训练未见物体，跨 embodiment 新技能则让 Realman 执行只在 WidowX 训练数据中出现过的动作技能。

### 5.2 Main Results

**【Paper】** 在 12 个“任务×协议”单元的等权平均上，VideoVLA 为 **63.0%**，略高于表中 CogACT 的 62.6%、$\pi_0$ 的 50.0%、SpatialVLA 的 47.1%、OpenVLA 的 26.0%。分组看，VideoVLA 的 WidowX-VM 平均为 53.1%，Google-VA 平均为 62.8%，Google-VM 为 73.1%（后者略低于 CogACT 的 75.2%）。这里平均不按各单元 trial 数加权，Google 的相同四项任务分别在 VM/VA 计入；0.4 个百分点差距未附多训练 seed 置信区间，不足以证明稳定领先。

**【Paper】** 真实 Realman 的 in-domain 三类任务**报告分数**平均为 **64.6%**，高于 CogACT（58.4%）、$\pi_0$（50.7%）、SpatialVLA（22.9%）和 OpenVLA（9.7%）。注意 Table 4 的 Place 分数 56.3 是抓起 87.5 与最终放置 25.0 的均值，64.6 又对 Pick/Stack/Place 三组均值再平均，因此含中间步骤得分，不能等同于所有 rollout 的完整任务成功率。按组取最终阶段等权平均会约为 $(70.8+66.7+25.0)/3=54.2\%$，这只是本文解释指标的重算，非论文另报结果。

**【Paper】** 在真实新物体测试上，VideoVLA 平均为 **50.6%**；相较 CogACT 的 26.9%、$\pi_0$ 的 21.8%，优势主要出现在 Clear Tape、Toy Duck 等多个物体，但不是每一项都第一。正文称 12 个物体，Table 5 实际列 13 个评估条件（同一黑瓶分直立/平放）；50.6% 是这 13 列的均值，每列 12 次。

**【Paper】** 上图的定性案例并列展示实际执行和 predicted video。论文把可执行动作带来的视频结果称为 visual imagination，并以此说明视频与动作在外观和运动上存在对应；定性图用于展示而非替代 success-rate 统计。

### 5.3 Ablation Study

| 消融（Google Robot, SIMPLER VM） | Pick Up | Move | Open/Close |     平均 |
| -------------------------------- | ------: | ---: | ---------: | -------: |
| CogVideoX-5B 预训练（默认）      |    92.3 | 82.9 |       66.2 | **80.4** |
| CogVideoX-5B 从头训练            |    18.6 | 10.8 |        9.2 |     12.6 |
| OpenSora-1.1 backbone            |    67.7 | 57.1 |       25.9 |     50.2 |

**【Paper】** 在固定 6 步动作预测的消融中，增加视觉长度有益：49 / 25 / 13 个 future frames 的平均成功率依次为 80.4% / 77.4% / 75.2%。作者据此认为更长视觉视野有益；但同时增加了 latent token、计算与监督信息，未证明仅时间跨度一项造成提升。所有上述 80.4% 消融只含 Google-VM 三任务，不含 Open and Place，也不等于主表四任务均值 73.1%。附录单向注意力对照（动作读视频，视频不读动作）为 75.5%，支持该设定中双向交互有益。

### 5.4 Generalization

**【Paper】** 在 Google 机器人训练数据未见的 10 个 SIMPLER 物体上，VideoVLA 平均 success rate 为 **65.2%**，对第二名 SpatialVLA（50.8%）领先 14.4 个点，并在 10 个物体中的 8 个上最好，每物体 25 次。“未见”限定 Google 的训练数据，不证明这些物体从未出现于 OXE 其他机器人或通用视频预训练。Google Robot 的跨 embodiment 新技能迁移平均为 **48.6%**，高于 CogACT 的 20.4% 与 SpatialVLA 的 18.9%。

**【Paper】** Realman 跨 embodiment 新技能迁移平均为 **58.0%**，超过 CogACT 的 35.1%。该实验将 WidowX 数据与 Realman 自采数据混合训练；测试物体已被 Realman 见过，仅这些技能没有其示教。因此是跨已适配 embodiment 的技能迁移，不能说 Realman 完全没有机器人训练数据。附录称每新技能 16 次，但表中 Wipe 的 8.3%/16.7%/41.7% 不符合单组 16 次的比例步长；仿真新技能“每项 20 次”也与若干表值不吻合，完整分组/聚合细节仍未交代。

## 6. 方法分析

### 6.1 为什么有效？

**【Analysis】** 预训练视频 DiT 已在大规模视频中学习“文本条件下可能发生什么”的统计规律。VideoVLA 将动作也放进同一去噪问题，迫使一个可用于 robot control 的低维输出与高维视觉后果同步。这比只用 action loss 多出两层约束：对象/指令的语义一致性，以及轨迹随时间的可见后果。

### 6.2 核心创新

**【Analysis】** 核心创新是 **joint visual-action diffusion**，而非仅使用 CogVideoX 初始化。若未来视频只由一个冻结模型离线打标签，动作模型未必能在 sampling 中获得视频 token 的逐步反馈；VideoVLA 的 token-level joint denoising 正是其同步策略优于异步策略的设计理由。

### 6.3 与已有方法的本质区别

| 方法范式                    | 主要预训练先验                      | 行为输出                          | VideoVLA 的差异                                              |
| --------------------------- | ----------------------------------- | --------------------------------- | ------------------------------------------------------------ |
| 理解型 VLA                  | VLM / vision-language understanding | 动作 token 或 action chunk        | VideoVLA 迁移视频生成能力，并预测动作的视觉后果。            |
| 独立 video planner + policy | 未来视频与控制器分离                | planner 输出视频，policy 输出动作 | VideoVLA 让 future video 与 action 在同一个 DiT 内联合采样。 |
| 纯 Diffusion Policy         | 机器人轨迹分布                      | 连续动作                          | VideoVLA 将视频 latent 作为联合目标和生成变量。              |

### 6.4 关键假设

**【Analysis】** 方法依赖三项假设：(1) 高质量通用视频先验能转移到相机视角下的机器人场景；(2) 训练数据中的 future video 与 action 已经时空对齐；(3) 联合生成学到的相关性足以跨越 embodiment 间不同的运动学和控制接口。第三项尤其强，因为同样的图像后果可能由不同 robot action 实现。

## 7. 局限性

### 7.1 作者明确提出的局限

**【Paper】** 最大限制是推理速度。面向真实部署时，预测 4 个 future latents（13 帧）和 6 个动作、执行其中 3 步，在单张 H100 上约需 1.1 秒；作者所称约 3 Hz 是动作输出量级，不是重新感知与重规划频率。作者将瓶颈归于 CogVideoX-5B，建议后续使用更小的 robot-oriented video generator、one-step denoising 或模型蒸馏。

### 7.2 自己分析得到的局限

**【Analysis】**

1. **想象不是验证。** 模型生成的未来视频与动作来自同一个生成模型，二者自洽不必然代表二者都对真实环境正确；论文的相关性分析也没有把 imagined future 接入显式选择、拒绝或闭环纠错机制。
2. **视觉后果未必可辨识动作。** 第三人称图像下，多种 action trajectory 可能产生相近未来帧；特别是接触力、精细夹爪状态、遮挡区域很难仅凭视频确定。
3. **公开复现链尚不完整。** 官方仓库已发布模型实现和推理示例，但没有完整训练/数据加载/机器人部署流程；论文的训练数据变换与全部评测细节不能只靠当前代码仓库复现。
4. **高成本限制控制频率与探索。** 上述秒级重规划在论文慢速 pick-and-place 场景得到验证，却难以应对快速接触、扰动恢复或需要大量 candidate sampling 的场景。

## 8. 启发与研究思考

**【Analysis】** VideoVLA 值得延伸的方向不是把视频长度一味加大，而是让 visual imagination 进入决策闭环：生成多个 action-video 样本，以视觉可达性、碰撞风险或目标进展为准则重排序；执行后比较真实观测和预测，检测模型失配并触发重规划。这样视频才从训练期 auxiliary target 升级为测试期的可用 world model。

**【Analysis】** 跨 embodiment 的下一步也应显式引入 embodiment token、运动学约束或 action canonicalization。VideoVLA 目前用统一的 7D wrist rotation/translation/gripper 表示降低差异，但不同臂长、坐标系、夹爪与低层控制器仍会把同一“想象结果”映射到不同可行动作。
