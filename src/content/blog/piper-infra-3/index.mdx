上一章准备好了 Ubuntu 22.04 和 ROS 2 Humble。本章接入官方的 Piper 驱动，在 RViz 中查看机械臂、设置目标姿态，并完成一次轨迹规划与执行，为后续编写控制程序准备好操作流程。

## 1. 配置官方驱动并启动 RViz

按照官方 [agx_arm_ros 仓库](https://github.com/agilexrobotics/agx_arm_ros)的 ROS 2 配置说明，完成 SDK、驱动、MoveIt 依赖、工作空间编译和 CAN 配置。下面使用 **Piper 单臂、agx_gripper 夹爪，CAN 接口为 `can0`**。

启动前，固定好机械臂底座，留出活动空间，让机械臂处于已校准的零位，并将空夹爪闭合。这条组合启动命令会启动控制节点、MoveIt 和 RViz，默认自动使能机械臂。

在已加载 ROS 2 和工作空间环境的终端中执行：

```bash
ros2 launch agx_arm_ctrl start_single_agx_arm_moveit.launch.py \
  can_port:=can0 arm_type:=piper effector_type:=agx_gripper
```

三个参数分别指定 CAN 接口、机械臂型号和末端执行器。启动后，RViz 会显示 Piper 模型，并加载用于规划和执行运动的 `MotionPlanning` 面板。

也可以先用官方的本地演示熟悉界面：

```bash
ros2 launch agx_arm_moveit demo.launch.py \
  arm_type:=piper effector_type:=agx_gripper
```

本篇截图由这条演示命令在本地运行后截取，操作对象是虚拟机械臂。下面按“设置目标 → 规划 → 预览 → 执行”的顺序练习。

`Displays → Global Options → Fixed Frame` 使用 `base_link`，让显示以机械臂基座坐标系为参考。选择 `Move Camera` 后，在当前 `Orbit` 视角中，左键拖动旋转视角，中键拖动平移，滚轮缩放。

后续主要使用 B 区的 `Planning` 标签页。左侧 `Commands` 放着 `Plan`、`Execute` 等按钮；中间 `Query` 用来选择规划组、起点和目标；右侧 `Options` 设置规划时间、尝试次数以及速度和加速度缩放。

三维视图中会同时显示模型和末端交互标记。设置目标时观察目标姿态，规划后观察动画与轨迹叠影，执行后再看模型更新到的位置。

## 3. 设置机械臂目标

这一轮让末端从当前姿态向上移动一小段。按图中①到⑤操作：

1. **选择规划组。** 将 `Planning Group` 设为 `arm`，对机械臂进行规划。
2. **设置起点与目标。** `Start State` 选择 `<current>`，以当前状态为起点；`Goal State` 选择 `home`，从这个预设开始编辑目标。`home` 对应模型的六轴零目标。
3. **设置轨迹缩放。** 将 `Velocity Scaling` 和 `Accel. Scaling` 都设为 `0.10`，调整规划轨迹的速度与加速度缩放。
4. **启用交互工具。** 点击工具栏中的 `Interact`。
5. **拖动目标。** 在三维视图中按住框出的红色箭头，沿标注方向向上拖动一小段。彩色箭头改变末端位置，圆环改变末端朝向。

## 4. 点击 Plan，预览运动轨迹

目标设置好后，点击左侧的 `Plan`。MoveIt 会根据起点、目标和模型约束生成轨迹，RViz 随后播放规划动画。

为了看清机械臂沿途经过的姿态，按图中①到④操作：

1. 点击 `Plan`，生成并预览轨迹。
2. 在 `Displays → MotionPlanning → Planned Path` 中勾选 `Show Trail`。
3. 将 `Trail Step Size` 设为 `10`，调整叠影显示的采样间隔。
4. 观察右侧的轨迹叠影，查看机械臂从起点到目标经过的姿态。

## 5. 执行已规划的轨迹

三个常用按钮可以这样理解：

| 按钮             | 操作                           |
| ---------------- | ------------------------------ |
| `Plan`           | 生成轨迹，并在 RViz 中预览     |
| `Execute`        | 将已经生成的轨迹交给控制器执行 |
| `Plan & Execute` | 连续完成规划和执行             |

刚开始练习时，先点击 `Plan` 查看轨迹，再点击 `Execute`，便于把目标设置、规划结果和执行过程对应起来。接入真实驱动后，执行时同时观察机械臂的实际运动和 RViz 中的状态更新。[MoveIt RViz 操作教程](https://moveit.picknik.ai/humble/doc/tutorials/quickstart_in_rviz/quickstart_in_rviz_tutorial.html)

## 6. 规划并执行夹爪开合

接着将操作对象切换到夹爪。官方模型提供了三个命名目标：

| 目标            | 含义     |
| --------------- | -------- |
| `gripper_open`  | 张开预设 |
| `gripper_half`  | 半开预设 |
| `gripper_close` | 闭合预设 |

这次使用半开目标，按图中①到④操作：

1. 将 `Planning Group` 切换为 `gripper`。
2. 保持 `Start State` 为 `<current>`，将 `Goal State` 设为 `gripper_half`。
3. 先点击 `Plan` 查看夹爪开合的规划，再点击 `Execute`。
4. 等状态显示 `Executed`，观察三维视图中的夹爪半开姿态。

随后可以选择 `gripper_close`，再按相同顺序完成一次闭合。这样就熟悉了机械臂和夹爪各自的规划组，以及从当前状态到命名目标的控制流程。

后续编写程序时，可以沿用这里的顺序：读取当前状态，设置目标，调用规划器，检查轨迹，再提交执行。RViz 则继续作为观察模型、目标和轨迹的窗口，帮助我们把程序中的控制步骤与机械臂运动对应起来。
