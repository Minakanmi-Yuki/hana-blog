## 1. 论文概述

本文核对 [arXiv v2 全文](https://arxiv.org/html/2604.08168v2)及[官方实现 commit 046fc99](https://github.com/GigaAI-research/ViVa/tree/046fc99dd96b29dcf7daa4737cc048042bf1357b)。价值标签的方向、失败惩罚与公开实现存在未闭合之处，见第 4.3、4.6 节。

**【Paper】** ViVa（Video-generative Value model）针对长时程机器人任务中的价值估计问题：单帧 VLM 能理解“现在有什么”，却不一定知道动作之后会发生什么。作者将预训练视频生成器 Wan2.2 改造成一个 value function，在给定三路相机图像和机器人本体状态后，同时预测 $K$ 步之后的本体状态与当前状态的标量 value。

![ViVa 方法总览（论文 Figure 2）](https://pic.hana0721.top/blog/paper-deep-dive-viva/viva-method.1zj00da5e9.webp)

### 一句话总结

**【Analysis】** ViVa 的关键不是让模型生成可观看的视频，而是借用“必须解释时空变化”的生成训练目标，为 value 表征增加未来本体状态监督，改善部分任务的错误响应。它是共享网络的辅助学习约束，并没有物理方程保证 value 必须与预测状态一致。

### 核心贡献

**【Paper】**

1. 将机器人 value estimation 定义为 future anticipation 问题，指出视频生成模型比静态 VLM 更适合表达交互动态。
2. 通过 latent injection 在不改 Wan2.2 核心 DiT 的前提下加入本体状态和标量 value 两种新模态。
3. 联合预测未来本体状态与 value，让两类目标通过同一 DiT 交互；这种耦合是学习得到的，不是显式动力学一致性证明。
4. 在衬衫折叠、纸箱包装、纸卷整理三个长时程任务上取得强相关性、事件敏感性和泛化表现；接入 RECAP 后平均成功率达到 80%。

## 2. 背景与相关工作

**【Paper】** VLA 在大规模预训练后已能执行多种操作，但现实交互具有 partial observability、接触动力学和 delayed feedback。RL 中的 value function 负责估计从当前状态出发的期望未来回报，并据此计算 advantage、筛选更好的行为。

以 GVL、TopReward 和 $\pi^*_{0.6}$ 为代表的方案主要使用 VLM：前两者从稀疏采样帧或 token 概率得到 value，后者在 RECAP 中用密集监督训练 VLM value model。**【Analysis】** 更准确的区别在于是否用生成目标显式学习时空变化，不能把所有 VLM baseline 简化为只看一帧：GVL 的排序输入就涉及多帧；密集训练的 VLM value 也可以学习进度。ViVa 因此选择视频生成先验，并将预测未来本体状态作为额外的 embodiment 约束。

## 3. 问题定义

**【Paper】** 在 MDP 中，时刻 $t$ 的联合观测为 $x_t=(o_t,q_t)$，其中 $o_t$ 是三路 RGB 视角，$q_t$ 是 公开实现中默认 14 维的 `observation.state`（其每一维的物理编码需由实际数据集确定，不能把末端位姿与关节角混为一谈）。策略 $\pi$ 的 value 定义为：

$$V^{\pi}(x_t)=\mathbb E_{\pi}\left[\sum_{k=t}^{T}r_k\mid x_t\right].$$

模型输入是当前的 `cam_left_wrist`、`cam_right_wrist`、`cam_high` 和归一化本体状态；输出是 $\hat q_{t+K}$ 与 $\hat v_t$，其中 $\hat v_t$ 应对应明确约定的回报或代价标签，不能在两种符号方向之间直接互换。实验固定 $K=50$。

任务包括：双臂折叠衬衫（最长 300 秒）、纸箱包装（最长 300 秒）和纸卷整理（最长 240 秒）。每个任务有 50 个 held-out episodes，并人工标注 milestone 与 error frames。

## 4. 方法

### 4.1 Overall Architecture

**【Paper】** ViVa 将七帧 latent 序列送入 Wan2.2：

`[blank, current state, left wrist, right wrist, high view, future state, value]`

前五帧是 clean conditioning，最后两帧是加噪 target；DiT 通过 flow matching 反演 target。**【Analysis】** 这里的“帧”是复用视频模型的数据容器：三路图像来自同一时刻，另有状态和标量占据的伪帧，并非七个连续时间点。联合去噪允许两个输出交互，但并不能排除网络仍借助静态外观或轨迹时间相关性预测标签。

### 4.2 核心模块

#### Latent injection

- **图像**：预训练时空 VAE 将每路图像压成 latent frame。
- **本体状态**：先归一化到 $[-1,1]$，再 repeat-padding 到 latent frame 的 $H'\times W'\times C'$ 个元素。
- **标量 value**：归一化后 broadcast 到整张 latent frame，使所有元素携带同一个值。
- **blank token**：因果 VAE 所需的零帧占位符。

#### Wan2.2 Diffusion Transformer

**【Paper】** 核心 DiT 不做结构修改，只用 latent injection 扩展模态。对目标 latent 注入高斯噪声，推理时固定条件前缀并反向积分。**【Code】** 同一样本两种目标共用一个噪声时间，噪声元素独立；并非各自采样独立 flow time。

#### RECAP 接口

**【Paper】** ViVa 替换 RECAP 中的 VLM value model，其他 advantage 估计、二值 improvement indicator 和 advantage-conditioned policy training 保持不变。两个 RECAP 变体都以 Gigabrain-0 为策略基础，因此比直接与不同 IL 模型比较更接近 value-model 对照；但 backbone、输出参数化、proprioception 输入与辅助目标同时变化，不能把全部差值仅归因于某一个模块。

### 4.3 关键公式

#### Flow matching loss

令干净 latent 为 $z_0$，高斯噪声为 $z_1\sim\mathcal N(0,I)$，插值路径为：

$$z_\tau=(1-\tau)z_0+\tau z_1,\quad \tau\sim\mathcal U[0,1].$$

DiT 预测恒定速度 $z_1-z_0$，总目标为：

$$\mathcal L=\lambda_{prop}\mathbb E\|v_\theta(z_\tau^q;\tau,c)-(z_1-z_0^q)\|_2^2+\lambda_{val}\mathbb E\|v_\theta(z_\tau^v;\tau,c)-(z_1-z_0^v)\|_2^2.$$

其中 $c$ 是五帧 clean prefix，$\lambda_{prop}=0.5$、$\lambda_{val}=1.0$（实验默认值）。第一项提供未来本体状态监督，第二项监督 value。注意这里的速度方向是干净样本到噪声，生成时从 $\tau=1$ 向 $0$ 积分，时间增量为负。公开代码对 1,000 个 scheduler 索引均匀抽样，再做 `shift=5` 的噪声日程变换，与公式中直接均匀采样 $\tau$ 也不完全相同。

#### Outcome-aware return

**【Paper】** 对长度为 $T$ 的 episode，非终止步奖励为 $1/T$；成功终止奖励为 0，失败终止奖励为 1。因此：

$$G_t=\begin{cases}(T-t)/T,&success\\(T-t)/T+1,&failure.\end{cases}$$

**【Analysis】** 按式子，$G_t$ 是随时间下降的**剩余代价**：成功结束为 0，失败结束为 1，因此越小越好。所谓 1.0 margin 只适用于相同归一化时间进度的成功/失败样本；两类完整区间的最小间隔并不恒等于 1。把它称为“越大越好的进度”会把优势方向反过来。

这里有三处需要区分的原始材料不一致。第一，第 4.2 节 ERS 把里程碑上升、错误下降当成正确响应，与上述代价方向相反。第二，第 3.2 节声称输出重映射为 $[0,1]$，而失败目标在 $[1,2)$，未交代如何进一步缩放并恢复方向。第三，公开 `VivaDataset._compute_value()` 实际只用 $(T-1-t)/(T-1)$（代码采用零起始索引），不读取成功标签，也不增加失败惩罚。模型输出还会 clamp 到 $[0,1]$。因此目前不能把公开实现说成完整复现 outcome-aware return；若要用于最大化回报的 RECAP，需先确定代价转价值的映射、奖励和 advantage 的一致约定，不能替作者默默补上一个负号。

#### Event Response Score

对标注事件 $k$，以事件前后窗口均值计算：

$$ERS_k=d_k\frac{V_{after}^{(k)}-V_{before}^{(k)}}{V_{before}^{(k)}+\epsilon},$$

其中 milestone 的 $d_k=+1$、error 的 $d_k=-1$。MS/ES 是两类事件的平均 ERS；MDR/ErrDR 是 ERS 大于 0 的检测比例。**【Analysis】** 这里的 $V$ 必须采用“越大越好”的方向，不能原样代入上面的代价 $G$。此外 ERS 依赖基线值和窗口 $w$，并不对平移/重缩放普遍不变；论文未完整给出窗口与 $\epsilon$ 的复现设置。EDR 只统计已人工标注事件处的变化方向，没有统计非事件帧误报，因而不是实时错误报警系统的 precision/recall。

### 4.4 Training

**【Paper】** 训练数据来自三任务的 demonstration 与两轮 RECAP rollout：第一轮每任务 150 成功/50 失败，第二轮 100 成功/50 失败；第 4.3 节还描述两种密集监督模型使用约 20 小时三任务混合示教。训练一个 epoch、batch size 192，使用 8 张 NVIDIA A800，$K=50$。给定成功/失败条数是收集后训练集的组成，不能反推每轮策略的自然成功率；示教与各轮 rollout 的完整训练清单、混合比例未发布。

**【Code】** `VivaDataset` 从 LeRobot 数据集中读取三路图像和 `observation.state`，以 `future_offset` 取未来状态；状态按训练集 min/max 归一化到 $[-1,1]$。`VivaModel.training_step` 对整段 latent 加噪，只在 future-state 与 value 两帧上计算 MSE flow-matching loss。

### 4.5 Inference

**【Paper】** 推理时只提供前五帧条件，reverse diffusion 生成 future-state/value 两帧。value latent 的元素均值经 $[-1,1]\to[0,1]$ 重缩放得到 $\hat v_t$；future-state latent 则重排为多份 14 维向量，在“副本”轴平均，还原各维预测。代码返回的未来状态仍在归一化坐标中，需训练集 min/max 才能反变换到物理单位。

**【Code】** `inference.py` 逐帧读取 episode，调用 `predict_value`，将预测值写回 parquet；脚本默认传入 1 个去噪步（模型方法自身默认 50）。论文称单步 DDIM，但实际执行的是 `FlowMatchScheduler.step` 的 Euler 更新 $z\leftarrow z+(\sigma_{next}-\sigma)v_\theta$；单步从 1 到 0 即 $z_0=z_1-v_\theta$。它保存 `prediction` 与 `prediction*(episode_length-1)` 的 `model_prediction`；后者依赖已知完整 episode 长度，是离线回填字段，不能当成在线已知的真实剩余时长。

## 5. 实验

### 5.1 Experimental Setup

![ViVa 的三个真实机器人任务（论文 Figure 3）](https://pic.hana0721.top/blog/paper-deep-dive-viva/viva-tasks.pg2u1s68s.webp)

三个任务分别考察柔性织物双臂协调、纸箱多阶段装配和纸张撕取/回卷。评估集每任务 50 个 episode，并标注关键里程碑与实际发生的错误。

### 5.2 Main Results

**【Paper】** Pearson/Spearman 全局相关性如下：

| 方法          | Shirt P/S         | Box P/S           | Paper P/S         |
| ------------- | ----------------- | ----------------- | ----------------- |
| GVL           | 0.276 / 0.263     | -0.081 / -0.114   | -0.099 / -0.096   |
| TopReward     | 0.118 / 0.090     | 0.503 / 0.499     | 0.318 / 0.241     |
| $\pi^*_{0.6}$ | 0.740 / 0.720     | **0.946 / 0.945** | 0.926 / 0.936     |
| ViVa          | **0.984 / 0.982** | 0.868 / 0.850     | **0.952 / 0.948** |

ViVa 在衬衫和纸卷上领先，纸箱上由 $\pi^*_{0.6}$ 领先。事件指标补充了全局相关性不能反映的局部变化：衬衫任务 ViVa 的 MDR/ErrDR 为 0.990/1.000，而 VLM baseline 为 0.407/0.500。但纸箱 MDR 是 **0.733 vs. 0.765**，ViVa 略低，因此“所有检测指标均领先”不成立。GVL/TopReward 是免训练稀疏查询，而两种密集模型有任务内监督；这组差距不能单独证明视频先验优于 VLM。

![ViVa 对细微操作错误的 value 响应（论文 Figure 5）](https://pic.hana0721.top/blog/paper-deep-dive-viva/viva-errors.3k8qzu7cnv.webp)

接入 RECAP 的真实机器人成功率为：

| 方法         |  Shirt |    Box |  Paper |     平均 |
| ------------ | -----: | -----: | -----: | -------: |
| $\pi_{0.5}$  |     60 |     40 |     40 |     46.7 |
| Gigabrain-0  |     50 |     50 |     20 |     40.0 |
| RECAP (VLM)  |     70 |     60 |     60 |     63.3 |
| RECAP (ViVa) | **90** | **70** | **80** | **80.0** |

**【Analysis】** 最直接的对照是 80.0% 对 63.3%，增加 **16.7 个百分点**；40%→80% 的 Gigabrain-0 对比还包含整套 RL 与新数据的作用。第 4.5 节没有明确报告每项最终真机测试的试验次数、多个训练种子或置信区间，不能借用前面的 50 个离线 episode 当作此表分母，也不能仅凭 10% 刻度断言每项试验恰好十次。

### 5.3 Ablation Study

**【Paper】** 架构消融显示：将 VLM 换成 video generator 后，衬衫 MDR 从 0.407 提升到 1.000；加入当前 proprioception 和 future-state prediction 后，纸卷 ES/ErrDR 达到 0.055/0.778。去掉预训练视频权重后，衬衫 ES 从 0.012 降至 -0.524。

**【Analysis】** 辅助未来状态主要改善部分错误响应，并非各列单调提升：纸箱从 VG-only 到 full ViVa，ES 0.004→0.026、ErrDR 0.449→0.612，但 MS 0.048→0.034、MDR 0.853→0.733；衬衫 VG-only 的 MDR 1.000 也高于 full 的 0.990。纸卷则从负 ES 改为正且四项都改善。预训练消融支持权重迁移有用，但没有等算力、等数据的其他预训练目标对照，不能进一步锁定收益只来自“学会物理动力学”。

![损失权重与预测 horizon 消融（论文 Figure 8/9）](https://pic.hana0721.top/blog/paper-deep-dive-viva/viva-loss.6f1f5mmjk5.webp)

在测试的候选中，作者选 $\lambda_{prop}=0.5$、$K=50$ 作为三任务折中；短/长 horizon 导致某些错误指标下降。“上下文不足/目标不确定性增大”是对此现象的解释，并非所有指标的严格最优或通用常数。

### 5.4 Generalization

**【Paper】** 在未见过的 pants folding 任务上，ViVa 的相关性为 0.819/0.799，**里程碑敏感性 MS** 为 0.037（baseline 0.016）；MDR 是 **0.643 对 0.397**，相对增加约 62%，绝对增加 24.6 个百分点。原文中的 0.643 是 ViVa 的 MDR，并非 baseline 或综合分数。这组 50 个裤子折叠 episode 只评估里程碑，作者明确没有评估未见物体的错误检测；不能从中推出 OOD error awareness 或 OOD 真机策略成功率。

## 6. 方法分析

### 6.1 为什么有效？

**【Analysis】** value 的监督本质上要求模型回答“当前行为是否把系统带向成功”。未来本体状态是一个低维、可检查的中间目标：它迫使共享参数同时解释当前观察与未来本体变化，可能让表征更重视夹爪/肢体配置。这里没有动作条件，预测的是数据中行为策略及其混合分布下的未来状态，既不是可执行动作，也不能回答“换一个候选动作会怎样”。视频 DiT 的时空先验则提供了跨帧的运动归纳偏置。

### 6.2 核心创新

**【Analysis】** 真正的创新是把 value 从一个孤立的 discriminative head，改写成生成序列中的一个 target frame；未来状态预测不是辅助可视化，而是额外的未来本体监督。共享去噪器不等于因果约束，未来状态合理也不保证 value 校准正确。

### 6.3 与已有方法的本质区别

两者都能接受任务内密集监督并学习进度，区别在预训练表征、目标参数化和未来状态辅助监督。ViVa 不生成未来 RGB 视频；作者尝试过该目标但 value 精度下降，推测高维视觉重建与简单标量的任务难度不匹配。这也说明“预测越多未来信息越好”不成立，需要控制辅助目标对 value 优化的干扰。

### 6.4 关键假设

1. 三路视觉和 14 维本体状态足以作为 MDP 状态的实用代理。
2. 预测固定 horizon 的未来状态能提供足够的 dynamics grounding。
3. 大规模通用视频预训练的时空先验可以迁移到机器人操作。
4. 归一化 return 的方向、范围与 RECAP advantage 一致；当前论文/代码尚未提供闭合的映射证据。

## 7. 局限性

### 7.1 作者明确提出的局限

**【Paper】** 受资源限制，作者尚未对 value model 做大规模预训练；跨任务泛化潜力仍留作未来工作。

### 7.2 自己分析得到的局限

**【Analysis】** 论文只评估三个任务、单一机器人形态与三路相机；代码依赖 Wan2.2-TI2V-5B 和多 GPU 训练，复现实验门槛较高。标量被重复到整帧，没有直接训练置信区间；多次噪声采样的方差也不能自动解释为校准后的成功概率。更直接的复现障碍是成败标签和事件指标的方向不一致、公开数据/策略 RL 闭环缺失，以及论文 batch 与公开配置不同。

## 8. 启发与研究思考

**【Analysis】** ViVa 给出的方向是“用生成模型做 critic”，而不是只把生成模型当 policy 或 world model。后续可以沿三条线推进：

- 让模型预测 action-conditioned future state，从 state value 走向 Q/advantage 建模；
- 用多步或不确定性采样估计 value interval，而不是单一标量；
- 在更多 embodiment 与跨任务数据上预训练，使视频先验真正转化为通用机器人动力学先验。
