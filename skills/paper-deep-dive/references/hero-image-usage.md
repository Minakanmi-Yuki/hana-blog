# Hero Image Usage

This is the shared cover-image allocation document for `Paper Deep Dive` posts. Read it before choosing `heroImage` and update it after assigning a cover.

## Selection Rules

1. Choose a Pixiv cover from the available pool below.
2. Prefer images with `Use Count = 1`.
3. Avoid any image already used by another `paper-deep-dive-*` post.
4. Do not use an image with `Use Count >= 3` unless the user explicitly overrides this rule.
5. If no count-1 image fits, choose a count-2 image, but only after checking that it is not already overused within the same collection.
6. After choosing an image, increment its count and add the new post to the `Current Posts` column.

## Maintenance

When a new post assigns a cover:

1. Increment the image's `Use Count`.
2. Add the new slug to its `Current Posts` cell.
3. Move the row to the correct pool if the count changes from 1 to 2, or from 2 to 3.
4. If a new Pixiv image is added, append it to the count-1 pool.
